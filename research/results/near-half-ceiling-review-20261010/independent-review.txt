Reviewer: one fresh-context medium-effort reviewer (Claude Code medium-reviewer agent).

Verdict: no materially different architecture it can vouch for; one re-prioritisation and one untested
construction principle.
1. The last six cycles are not defensible for this goal. conj:cumulative-index-span, if proved, caps random
parity-clause systems at the product index, a class already cut off for the every-depth form in the model;
conj:paired-row-symbols gives a linear deficit, again an exclusion. The binding gap is that no F_2 lower bound
above about n/4 exists for any family. With six cycles: prove colon regularity (thm:colon-regular-closure) for
random k = 2 rows at degree 3, then for growing D; a failed first moment there is still informative. The
measured evidence (indices 3 to 5, n <= 28) says nothing about degree near n/2.
2. Where to look: a polynomial cover has its measure on rows of codimension O(log n); in the model rows on k
variables lose at least n ln k/(2k). The only reading left open: rows that are bundles, scope k = n^delta
parity forms, forbidden set a union of polynomially many log-codimension subspaces of constant total measure
(tribes-like; not symmetric, by lem:weight-interval-subspace-bound); thm:saddle-deficit-bound then allows
deficit about n^(1-delta) log n, borderline. Smallest test: does the deficit scale as ln k/k in the scope or
in the term width; if term width, the class is cut off and every class it can name is the open problem
restated. The model is unvalidated for dependent rows. Non-flow multiplicative systems formally open, not a
priority.
3. Different endpoint: the two-level form, cor:two-level-regularity-reduction: an unsatisfiable family of
width k -> infinity, 2^k polynomial, colon regular through n/2 - o(n). It serves only the depth with no log
factor; whether that depth is already known is unverified, check before investing. The criterion fails when
two rows share a form and is sufficient only. No alternative measure seen.
4. Assessment: a proved transfer and a map of exclusions but no lower-bound mechanism past n/4; the open
statement is untouched because cycles go to ceilings and models. The every-depth goal does not look reachable
by this line as it stands. A two-level result via colon regularity is the only target with a visible proof
path and should be declared the working endpoint, with the every-depth goal recorded as lacking a mechanism.
