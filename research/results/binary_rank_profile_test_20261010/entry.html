Use the right support and the right dual

Read the rank-code definitions, Singleton statement and trace-dual counting proof in Ravagnani, Theorem 8 and Lemmas 27–30/Theorem 31. Read the support conventions, Example 2.5, Definitions 4.1–4.2 and Theorem 4.3 with proof in Gorla–Jurrius–López–Ravagnani. The latter distinguishes row from column support and warns that separately optimal supports need not form a chain. No transposition-invariant rank-weight definition is silently substituted for our fixed orientation.

Let \(F=\mathbb F_q\), \(V=F^k\), and \(0\ne W\subseteq V\otimes H\), of dimension \(m\). Replace \(H\) by the span of all coordinate values of elements of \(W\), so it is the minimal output space; write \(N=\dim H\). For \(\lambda\in H^*\), let \[ M_\lambda=(\operatorname{id}_V\otimes\lambda)|_W:W\to V, \qquad\mathcal C=\{M_\lambda:\lambda\in H^*\}\subseteq\operatorname{Mat}_{k\times m}(F). \] The map from \(H^*\) is injective by minimality, hence \(\dim\mathcal C=N\). For a subcode \(\mathcal D\subseteq\mathcal C\), use the explicit oriented support \[ \sigma(\mathcal D)=\dim\sum_{M\in\mathcal D}\operatorname{rowsp}(M)\subseteq W^*. \] This is a row-support dimension, not a minimum-rank statistic of one matrix.

Lemma (contraction support profile). For any complete output flag \(0=H_0\subset\cdots\subset H_N=H\), let \(W_j\subseteq V\) be the image of \(W\cap(V\otimes H_j)\) in \(V\otimes(H_j/H_{j-1})\), identified with \(V\), and let \(r_j=\dim W_j\). Put \[ \mathcal D_i=\{M_\lambda:\lambda(H_{N-i})=0\},\qquad0\le i\le N. \] Then \(\mathcal D_i\) is a complete flag of the code and \[ r_{N-i+1}=\sigma(\mathcal D_i)-\sigma(\mathcal D_{i-1}),\qquad \sigma(\mathcal C)=m. \tag{1} \] In a basis \(w_1,\ldots,w_m\) of \(W\), the trace dual of \(\mathcal C\) is \[ \mathcal C^\perp=\ker\Psi,\qquad \Psi(R)=\sum_{i=1}^k\sum_{j=1}^m R_{ij}(w_j)_i\in H. \tag{2} \] In particular it has dimension \(km-N\).

Proof. The common kernel of the matrices in \(\mathcal D_i\) is \(W\cap(V\otimes H_{N-i})\). Its codimension in \(W\) is the dimension of the span of their row functionals, namely \(\sigma(\mathcal D_i)\). Subtract consecutive kernel dimensions to obtain (1). The common kernel for the full code is zero, proving its total support dimension. For (2), \[ \operatorname{Tr}(RM_\lambda^{\mathsf T}) =\lambda\!\left(\sum_{i,j}R_{ij}(w_j)_i\right). \] Vanishing for every \(\lambda\) is equivalent to \(\Psi(R)=0\). Its image is \(H\) by minimality, so rank-nullity gives the dimension. \(\square\)

For the actual image \(w_j=([Ag_i f_j])_i\), with fixed preimages \(f_j\) in the allowed multiplier domain, equation (2) says \[ \Psi(R)=\left[A\sum_i g_i\left(\sum_jR_{ij}f_j\right)\right]. \] All products fit the original tuple-image window. Thus the true trace dual consists of polynomial relations among these products. It is not automatically the earlier coefficient-choice code, formed by varying a row in \(V^*\). That code uses the other contraction of the tensor and in general even has a different matrix shape. A MacWilliams transform between the two cannot be assumed.

What the minimum-rank information actually gives

In the raw-variable setting of the full rectangular-annihilator proof, with unsatisfiable old generator degree at most \(d_0\), prefactor degree \(a\), full multiplier cutoff \(K\ge d_0-1\), and \(a+K+1\le D\), every nonzero matrix in \(\mathcal C\) has rank at least \(K+2-d_0\). Extending a functional from the minimal output space to the recorded \(H_A\) does not change its contraction; nonzero values on the output ensure the extended annihilator is nonzero. This is precisely the existing theorem, not a new rank bound. It does not apply automatically when the inputs are arbitrary nonlinear parent mixtures instead of all old variables.

If a nonzero subcode \(\mathcal D\) has dimension \(j\), minimum rank at least \(d\), and row-support dimension \(t\), choose column coordinates adapted to that support. It becomes a code of \(k\)-by-\(t\) matrices. Deleting any \(d-1\) columns is injective on it, as a matrix supported in those columns has rank at most \(d-1\). Deleting \(d-1\) rows is also injective. Therefore \[ j\le k(t-d+1),\quad j\le(k-d+1)t, \qquad \sigma(\mathcal D)\ge \max\left\{d-1+\lceil j/k\rceil,\ \lceil j/(k-d+1)\rceil\right\}. \tag{3} \] This is the elementary puncturing argument behind Singleton. It provides lower bounds on cumulative support, not an upper bound on the sum of increments exceeding a row budget. The following optimal-code control shows that this distinction persists even at the strongest possible minimum rank.

An optimal code with only wide nonzero fibres

Proposition (optimal code fibres). For every prime power \(q\), integer \(d\ge2\) and \(\ell\ge1\), there are spaces \(V,H,W\) as above with \[ \dim V=d,\qquad\dim H=\dim W=d\ell, \] whose contraction code has dimension \(d\ell\) and every nonzero matrix of rank \(d\), attaining the rank-metric Singleton bound. Under every complete output flag, exactly \(\ell\) nonzero fibres have dimension \(d\); all other fibres are zero. Nevertheless for every nonzero coefficient row, and more generally every matrix \(B\) of rank \(1\le h<d\), \[ W\cap(\ker B\otimes H)=0, \qquad \sum_j\dim(W_j\cap\ker B)=\ell(d-h)>0. \tag{4} \] Thus all flag mass lies in fibres wider than \(h\), while the actual intersection vanishes.

Proof. Let \(E=\mathbb F_{q^d}\), take \(V=E\) as an \(F\)-space, and identify \(H^*\) and an input space with \(E^\ell\). For \(f\in E^\ell\), define \(T(f)\in V\otimes H\) by its contraction map \[ \lambda\longmapsto\sum_{j=1}^{\ell}\lambda_j f_j. \] Set \(W=T(E^\ell)\). For nonzero \(f\), one coordinate \(f_j\ne0\), so this map is onto \(E\). In particular \(T\) is injective, \(\dim W=d\ell\), and the minimal output space is all of \(H\). Symmetrically each nonzero \(M_\lambda:f\mapsto\sum_j\lambda_j f_j\) is onto \(E\), of \(F\)-rank \(d\). The code has dimension \(d\ell\). Deleting \(d-1\) rows from any full-minimum-rank code in \(\operatorname{Mat}_{d\times d\ell}(F)\) gives dimension at most \(d\ell\); equality here proves optimality.

Use the nondegenerate trace pairing to identify the dual of \(E^\ell\) with itself. The row support of \(M_\lambda\) is then the \(F\)-space \(E\lambda\). For a subspace \(S\subseteq E^\ell\) of coefficient vectors, its joint row support is \(\operatorname{span}_E S\), of \(F\)-dimension \(d\dim_E\operatorname{span}_E S\). Along any complete \(F\)-flag in \(E^\ell\), adjoining one vector increases that \(E\)-dimension by zero or one. It increases a total of \(\ell\) times. Equation (1) gives exactly the asserted fibre widths, independently of the flag. The trace pairing used here is nondegenerate because the finite-field trace is nonzero and multiplication by a nonzero field element is invertible; it is not a source moment pairing.

For \(f\ne0\), the contraction map of \(T(f)\) is onto \(V\). Its composition with a nonzero \(B\) therefore cannot vanish. This proves the first statement in (4). Every nonzero flag fibre equals the whole \(V\), so its intersection with \(\ker B\) has dimension \(d-h\), proving the second. All matrices are over \(F\); the extension field constructs the code, not legal nonbinary assignments in a binary source. \(\square\)

This does not realize an arbitrary rank code as a multiplication image in the hard old quotient. It refutes the attempt to infer small fibre mass from minimum rank or even MRD optimality alone. The existing positive-clause control separately gives an actual proper-quotient case where a chosen row family has zero intersection despite every flag expression staying positive. Thus the loss is not cured by insisting that a good choice must first have a small flag certificate.
