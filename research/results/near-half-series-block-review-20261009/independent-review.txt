Reviewer: one fresh-context medium-effort reviewer (Claude Code medium-reviewer agent).

Verdict: no materially different architecture it can vouch for.
Why known methods stop near n/4 (its own argument, unverified): expansion arguments use the boundary of a
clause set of size in [r/2, r]; boundary at most k times the set size and at most n; boundary n - o(n) at
size r/2 forces rk/2 >= n - o(n), near-disjointness at size r forces rk <= n: incompatible; so boundary at
most about n/2 and certified degree at most about n/4, in any family. A two-level result for random CNFs of
width c log n needs a non-expansion method; none exists over F_2. Two levels is not a cheaper target.
Proposal 1, dense rows: random codimension-w subspaces on dense forms; a dense row has the same profile as a
variable row by affine invariance; closest exclusion the dimension count: span can be full once
2sw/n <= ln Sigma; a random cover needs Sigma ~ n ln 2, deficit about n/(2c). Test: compare unit entry for
dense and variable rows at v <= 20.
Proposal 2, barely-covering covers that are not paddings: Sigma = 1 + o(1/log n), not odd, evenly covered
set in no proper subspace of small codimension. Test: prove or refute that every cover with Sigma < 1 + 2^-w
has E inside one row's subspace.
Constant-fraction engine: thin closure is again "half" in a nonlinear dimension; only natural source is
extension variables; expects levels too large.
Assessment: out of reach by this approach with present methods; needs both a cover with Sigma -> 1 whose
hardness is not inherited (or syzygy-rich rows without binomial structure) and a non-expansion lower-bound
method over F_2.
