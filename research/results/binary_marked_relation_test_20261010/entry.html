The designated row changes the existence question

Lemma (marked relation threshold). Let \(F=\mathbb F_q\), \(m\ge1\), \(s\ge2\), and \(\mathcal R\subseteq\operatorname{Mat}_{s\times m}(F)\) be an \(F\)-linear subspace of codimension \(t\). Call a rank-one matrix marked when its first row is nonzero. If \(t<m\), then for every \(u\in F^s\) with \(u_0=1\), there is a nonzero \(v\in F^m\) with \(uv^{\mathsf T}\in\mathcal R\). The threshold is sharp for a guarantee depending only on \(t,s,m\): at every \(m\le t\le sm\) some such code has no marked rank-one matrix. At \(t=m\), \(s=2\), \(m\ge2\), failure can occur even when projection to the first row is surjective.

Proof. For fixed \(u_0=1\), the subspace \(\{uv^{\mathsf T}:v\in F^m\}\) has dimension \(m\). Its intersection with a codimension-\(t\) subspace has dimension at least \(m-t\). For sharpness take any dimension-\((sm-t)\) subspace of the space whose first row is zero, which has dimension \((s-1)m\). For the surjective-projection assertion, choose \(\alpha\in\mathbb F_{q^m}\setminus F\), and let \(A\) be multiplication by \(\alpha\) in an \(F\)-basis. The graph code with rows \(v^{\mathsf T},(Av)^{\mathsf T}\) has dimension \(m\), codimension \(m\), and surjective first-row projection. A nonzero rank-one member would give \(Av=cv\) for \(c\in F\), contradicting \((\alpha-c)v\ne0\). This is an abstract code calibration, not an asserted PC multiplication realization. \(\square\)

Apply the criterion to complete source relations

Work over \(\mathbb F_2\) with a degree-\(D\) pseudoideal \(J\) containing old Booleanity. Let \(S\) be an \(m\)-dimensional space of surviving weight classes, represented by linearly independent classes of polynomials \(f_1,\ldots,f_m\) of degree at most \(b\). This takes the quotient by weights already in \(J\) before counting dimension. Take old inputs \(g_1,\ldots,g_r\) of degree at most \(\delta\ge1\), and permitted binary polynomial features \(\phi_1,\ldots,\phi_a\) of degree at most \(T\ge1\). For an accuracy-one source let \(B\ge2\delta+1\) cover all original companion and fresh-field degrees, and require \(b+TB\le D\).

For a matrix \(R\) with rows indexed by \(0\) and pairs \((j,l)\), write \(f_R(\eta)=\sum_kR_{\eta,k}f_k\). Define the linear relation map \[ \mathcal L(R)=\left(\left[g_i f_R(0)-\sum_{j,l}g_i g_j\phi_l f_R(j,l)\right]\right)_{i=1}^r, \qquad \mathcal R=\ker\mathcal L. \tag{1} \] Every displayed product fits \(b+2\delta+T\le b+TB\). Replacing any representative by an equivalent one preserves the map by bounded absorption in this same window. A marked rank-one matrix has a unique representation \(R=uv^{\mathsf T}\) with \(u_0=1\). Put \(f=\sum_kv_kf_k\ne0\bmod J\) and \(a_j=\sum_lu_{j,l}\phi_l\). Equation (1) then says precisely \[ f g_i\left(1-\sum_j a_jg_j\right)\in J \quad\text{for every }i. \tag{2} \] Conversely every choice of \(f\in S\setminus\{0\}\) and binary feature coefficients satisfying (2) gives such a marked matrix. The fresh fields are also satisfied: every binary polynomial \(a_j\) has \(a_j^2-a_j\) in the Boolean ideal through degree \(2T\), so its weighted consequence fits \(b+2T\le D\). Thus these are complete accuracy-one maps. Replaying a degree-\(B\) original proof still uses \(b+TB\), not a canceled image degree.

For higher accuracy, one may activate this row and set the other rows to zero, but must charge the original \(B\ge h(\delta+1)+\delta\). That gives only a sufficient subclass of legal maps. Arbitrary multiple active rows introduce coefficient products; equation (1) is not claimed to encode them linearly. Likewise the linear code above is a new relation map for the complete one-row error expressions, not automatically the trace dual from the preceding contraction tensor.

The lemma's condition is \(\operatorname{rank}\mathcal L<m\). Its proof works already for \(u=(1,0,\ldots,0)\), producing \(fg_i\in J\) for all \(i\), with every source coefficient zero. More precisely the restriction \(f\mapsto([fg_i])_i\) has rank at most \(\operatorname{rank}\mathcal L\). This is exactly the common-kernel criterion on the same surviving domain; no new code estimate is used. If that restriction is injective, this codimension-only sufficient condition cannot hold. This does not exclude a successful marked matrix at much larger codimension.

An actual source distinguishes the three tests

Take two old Boolean variables \(x,y\), their degree-three Boolean consequence space, and the complete accuracy-one tuple \((x,y,x+y)\). This is a satisfiable control, not the inconsistent hard family. Allow only the weight domain \(S=\langle1\rangle\), so \(m=1,b=0\), and retain original \(B=3\).

With constant coefficient features, the relation vector \((0,1,1,1)\) is nonzero and rank one but unmarked: \(x+y+(x+y)=0\). No marked relation exists. Indeed a constant-coefficient sum of the inputs is \(q=ax+by\); vanishing of all companions at \((1,0)\) and \((0,1)\) forces \(a=b=1\), while at \((1,1)\) it then has \(q=0\), violating the first companion. There is no nonzero alternate weight in the chosen one-dimensional domain. This objection rejects only constant maps at that weight budget.

Permit the affine features \((1,x,y)\) instead. The complete map \[ a_1=1+y,\qquad a_2=1,\qquad a_3=0 \] has \(P=1+\sum_j a_jg_j=(1+x)(1+y)\). Its first two companions are \((x^2+x)(1+y)\) and \((y^2+y)(1+x)\), and the third is their sum. These are literal Boolean certificates through degree three. The only nonzero fresh-field image is \(a_1^2+a_1=y^2+y\). Thus weight one survives and all complete fields/companions vanish at \(T=1,D=3\), respecting \(b+TB=3\). Both the constant and affine relation maps have codimension three; the latter succeeds far beyond the sufficient threshold \(t<m=1\). No ambient codimension improvement explains the success: the actual polynomial relations do.

Enlarging the weight domain instead also repairs the constant map: choose \(f=x\), \(a_1=1\), \(a_2=a_3=0\), retaining the original replay ceiling \(b+B=4\). This separates a failed fixed domain from an obstruction to all weighted maps. Extending the field alone is not a repair: the weighted coefficient grid and complete descent retain fresh fields and the same nonzero-weight requirement.
