What R1 suggests.
- Unconditional (a, b), from memory: none with fixed b > 0; Vinogradov-Korobov saves only
  exp(-c log N / (log tau)^(2/3)).
- R1 is lossy, not a restatement. If zeta has no zeros with sigma > theta near tau_0, the explicit formula (memory)
  gives |Z| << N^theta log^2 + N/tau; that fits R1 exactly when b = a(1 - theta), b <= 1; then
  b^3/a^2 = a(1 - theta)^3 <= (1 - theta)^2, so the output is sigma >= 1 - (1 - theta)^2.
- Ceiling at RH strength: (a, b) = (2, 1) returns 3/4. Zeros on the line make Z of size N^(1/2).

- A route through R1 as stated cannot exclude a zero with 1/2 < Re s <= 3/4; it needs exponent b/a.
  The cubic loss presumably comes from R2 applied to about log tau zeros in a unit window.

Proposal A, sharpened local converse: if |Z(tau_0, N1, N2)| < N^(1/2 + eps) for all tau_0^eps <= N <= N1 < N2 <= 2N,

Proposal B, heat flow: a pair at height T that is real at time c/log T was real at time 0. Breaks: backward flow
