Extension representatives need not preserve polynomial images

Proposition (representative image gap). Let \(q\ge0\), \(r>q+1\), and let a free linear matroid have independent elements \(e_1,\ldots,e_r\). For the family of all singleton sets, any \(q+1\) of those singletons form a \(q\)-representative family. But replacing coordinate features \(x_1,\ldots,x_r\) by that subfamily changes the degree-one word space with initial domain \(\langle1\rangle\) from dimension \(r+1\) to \(q+2\).

Proof. A set of at most \(q\) ground elements misses one of the \(q+1\) retained elements. Adding that singleton remains independent in the free matroid, so every permitted extension is preserved. In the Boolean polynomial algebra, one and the distinct coordinate variables are linearly independent. The two dimension statements follow. \(\square\)

This tests using the representative-family property as a claim of image preservation. It does not refute Fomin–Lokshtanov–Panolan–Saurabh, Theorem 3.7: its exterior-algebra construction has rank \(p+q\), and the larger-rank application first truncates the matroid. Such a truncation is not automatically a degree-paid map preserving our old quotient. The example is an all-parameter auxiliary control, not a hard proof source.

An auxiliary binary join matrix has a small factorization

Lemma (binary join factorization). Let \(V=\mathbb F_2^r\), \(r\ge0\). On any two finite families of subspaces define \(H_{U,W}=\mathbf1_{U+W=V}\). Set \(C_{U,a}=\mathbf1_{a|_U=0}\), indexed by \(a\in V^*\). Then over \(\mathbb F_2\), \(H=C_{\rm left}C_{\rm right}^{\mathsf T}\), so \(\operatorname{rank}H\le2^r\). If both families contain every subspace, the rank is exactly \(2^r\).

Proof. The product entry counts linear functionals vanishing on \(U+W\). There are \(2^{r-\dim(U+W)}\), whose parity is one exactly when \(U+W=V\). This proves the factorization. For the full family, the row for \(U=V\) is the unit vector at the zero functional. For each nonzero \(a\), the row for \(U=\ker a\) is the sum of that unit vector and the unit vector at \(a\), since over \(\mathbb F_2\) its annihilator is \(\{0,a\}\). Thus \(C\) has full column rank \(2^r\). Its transpose is onto, so \(CC^{\mathsf T}\) has the same rank. The case \(r=0\) is the one-by-one matrix \((1)\). \(\square\)

This is an analogous incidence calculation to the Bodlaender–Cygan–Kratsch–Nederlof connection-matrix factorization, Lemma 3.13 and Appendix B.1, applied here to subspace joins. It is an elementary incidence calculation, not an independent novelty claim. It controls a specified auxiliary compatibility matrix; no map from all actual feature-word images to these states with affordable \(r\) has been supplied. The exact full-family rank also prevents claiming a uniformly smaller state factorization for this matrix.

A single stabilizer projector is not closed under the source parity operation

Proposition (stabilizer parity gap). For every \(n\ge4\), let \(P,Q\) be the diagonal projectors on complex \(n\)-qubit space for the predicates \(x_1x_2=1\) and \(x_3x_4=1\). Each is a stabilizer-code projector, but the diagonal projector for their Boolean XOR is not: it has rank \(3\cdot2^{n-3}\), which is not a power of two.

Proof. Each predicate fixes two bits and therefore defines a common eigenspace of two independent signed \(Z\) Pauli operators. XOR holds on \(3+3=6\) assignments to the first four bits, with the other bits free, giving rank \(6\cdot2^{n-4}\). For a nonzero stabilizer code with \(k\) independent commuting Pauli generators and no negative identity, its projector is the average of the \(2^k\) group elements. Only the identity has nonzero trace, so its rank is \(2^{n-k}\). This proves the mismatch. \(\square\)

The definition and dimension statement are in Gottesman, Section 3.2. This is a complex auxiliary representation of Boolean predicates, not an identification of our binary charged pseudoideal with a quantum state space. Mixtures of stabilizer projectors, other tensor descriptions and ordinary weighted error removal are not excluded. The control rejects only automatic closure in a single stabilizer object.
