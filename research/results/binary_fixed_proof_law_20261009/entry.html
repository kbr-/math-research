One common restriction, with both matrix sides

Work over \(\mathbb F_2\). Let \(m>n\), let \(n\) be even, and fix a pairing of the inner indices. Fix \(T\in\mathrm{GL}_n(2)\) and a nonempty union \(L\) of live pairs, of size \(n'\ge2\). The basis and live set may be sampled after a fixed proof, but are conditioned on throughout the calculation. Use \[ A_{\rm old}=AT,\qquad B_{\rm old}=T^{-1}B. \] For every dead pair \(\{u,v\}\), set \(A_{\cdot u}=A_{\cdot v}=a_{uv}\) and \(B_{u\cdot}=B_{v\cdot}=b_{uv}^{\mathsf T}\), with all entries of all vectors \(a_{uv},b_{uv}\) independent uniform bits. This is the recorded hardness-preserving law. Finally identify live \(A_{ik}=B_{ki}=X_{ik}\) and add the functional PHP base. Its row equations are \(R_i=\sum_{k\in L}X_{ik}+1\).

All fixed labels preserve residual old hardness: the degree-\(D\) matrix barrier holds for \(n'\ge2D-1\), \(D\ge2\). For the literal CNF boundary with basis change retain the degree-two gate substitution and its \(\max(2D,6)\) ceiling. The affine input calculation below does not improve that gate boundary.

For one actual tuple with \(s\) positions write, before sampling, \[ g_\alpha=c_\alpha+\sum_{i,k}C_{\alpha,ik}(A_{\rm old})_{ik} +\sum_{k,i}D_{\alpha,ki}(B_{\rm old})_{ki},\quad \alpha\in[s]. \] Set \(C'_\alpha=C_\alpha T^{\mathsf T}\), \(D'_\alpha=T^{-\mathsf T}D_\alpha\), and \(E_\alpha=C'_\alpha+(D'_\alpha)^{\mathsf T}\). Concatenate all dead-pair label bits into a single vector \(\xi\). Define the matrix \(Z\), with rows indexed by \(\alpha\), by the coefficients \[ Z_{\alpha,(uv,A,i)}=C'_{\alpha,iu}+C'_{\alpha,iv},\qquad Z_{\alpha,(uv,B,i)}=D'_{\alpha,ui}+D'_{\alpha,vi}. \] Then the tuple after restriction and live identification is exactly \[ g_\alpha=c_\alpha+(Z\xi)_\alpha+\sum_{i,k\in L}E_{\alpha,ik}X_{ik}. \tag{1} \]

Choose one live index \(k_*\). Eliminate \(X_{ik_*}\) using \(R_i\): write the other live variables as a vector \(x\), and put \[ c'_{\alpha}=c_\alpha+\sum_i E_{\alpha,ik_*},\qquad H_{\alpha,(i,k)}=E_{\alpha,ik}+E_{\alpha,ik_*}\quad(k\ne k_*). \] Thus (1) has row-reduced form \(c'+Z\xi+Hx\). The reduction uses only linear row axioms. Row and column exclusions are not silently assumed to follow from this affine parameterization; it describes a larger cube than the matching domain.

Exact probability and a legal row

Lemma (paired affine law). Let \(\pi:\mathbb F_2^s\to\mathbb F_2^s/\operatorname{im}H\), \(q=\pi c'\), and \[ \kappa=\dim\operatorname{im}(\pi Z) =\operatorname{rank}[H\ Z]-\operatorname{rank}H. \] Conditional on \(T,L\), the probability that the affine system \(g_\alpha=0\) is consistent modulo the row equations is \[ p_{\rm con}=\begin{cases}2^{-\kappa}&q\in\operatorname{im}(\pi Z),\\0&\text{otherwise}.\end{cases} \tag{2} \] Whenever it is inconsistent, there are binary constants \(\lambda_\alpha,\mu_i\) such that \[ 1+\sum_\alpha\lambda_\alpha g_\alpha=\sum_i\mu_iR_i. \tag{3} \] In a complete ENS block on this tuple, at any positive accuracy, set its first coefficient row to \(\lambda\) and every other row to zero. Every companion image has an ordinary old-axiom certificate through degree two; all coefficient-field equations map to zero.

Proof. The residual affine system is consistent exactly when \(c'+Z\xi\in\operatorname{im}H\), or \(\pi Z\xi=q\). A uniform binary vector maps uniformly onto the image of a linear map, because all fibers are cosets of the same kernel. This proves (2), including both the rank-zero and inaccessible-offset cases. If inconsistent, separation in the finite vector space supplies \(\lambda\) with \(\lambda H=0\) and \(\lambda(c'+Z\xi)=1\). Undoing the row substitution gives (3), with \(\mu_i=\sum_\alpha\lambda_\alpha E_{\alpha,ik_*}\). Conversely (3) precludes a simultaneous affine zero, so this is exactly the failure probability of this particular row-span normalizer.

The specialized product is \(P=1+\sum_\alpha\lambda_\alpha g_\alpha=\sum_i\mu_iR_i\). For every input position \(\beta\), its companion is \(g_\beta P=\sum_i\mu_i g_\beta R_i\), through degree at most two. For a mixed affine tuple, its maximum input degree is \(\delta=1\); for each position of original degree \(d_\beta\in\{0,1\}\), the displayed certificate has degree at most \(d_\beta+1\le d_\beta+h(\delta+1)\). Thus it fits each original companion cost, including constant positions, rather than only the maximum block cost. If every input is constant, inconsistency means some input is one and the product is literally zero, with no certificate cost. Fresh coefficient fields vanish at binary constants. \(\square\)

Simultaneous consequence. For an inventory of \(M\) fixed old-affine tuples sharing the same \(T,L,\xi\), form \(p_a\) by (2). If \(\sum_a p_a<1\), some common label assignment makes all tuples inconsistent and removes all these blocks with the legal constant rows just described. This is the union bound, not independence between blocks. All residual old systems at these labels stay in the same hard degree window. Later blocks retain their actual substituted inputs and coefficient domains; a constant specialization of the removed blocks does not increase their original charges. Any gate-boundary cost was paid separately before this statement. This consequence is a scoped normalization, not a claim that the rank premise follows from small proof size.

Controls that decide what the formula buys

A useful event. Take \(T=I\) and inputs consisting of \(s\) distinct fixed-label coordinates, using dead-pair/side/row combinations that are independent bits. Then \(H=0\), \(Z\) has full row rank \(s\), and \(p_{\rm con}=2^{-s}\). The normalizer succeeds exactly when at least one input becomes one. An inventory whose tuples each have this property can be treated when \(M2^{-s}<1\), even when different tuples share labels. This recovers the ordinary fixed-literal pruning event in the actual paired law; no new generic pruning theorem is claimed.

The fixed distinct-row control survives the row quotient. Take \(g_i=(A_{\rm old})_{i1}\) on \(r\) distinct outer rows, fixed before a uniform \(T\), with \(L\) fixed or sampled independently of \(T\). Let \(v=(T_{k1})_{k\in L}\). If \(v\) is neither all zero nor all one, each row-reduced form has a nonzero homogeneous part and different forms use disjoint row variables. Thus \(H\) has full row rank \(r\), the quotient is zero, \(\kappa=0\), and (2) gives consistency probability one, for every dead label. The probability of this event over the common basis is \[ 1-\frac{2^{n-n'+1}-1}{2^n-1}, \tag{4} \] because the first column is a uniform nonzero vector, and the two exceptional live projections have \(2^{n-n'}-1\) and \(2^{n-n'}\) preimages. This is a post-row-reduction strengthening of the preceding raw control, not a lower bound in the full functional PHP quotient. Higher-degree collision equations may still help, as they do for the already removable column family.

The old core-cost control and its later positive normalization were both reread before choosing this test. Repeating the fact that a common basis preserves raw dimensions would add no mechanism. Formula (2) instead makes a genuine removal event explicit, but (4) shows that the distribution does not force it, even after row equations. The handoff's nested-core theorem remains useful with certified small residuals; neither (2) nor the basis change supplies them for arbitrary mixed inputs.

What remains for actual proof errors
