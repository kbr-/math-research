The bounded-group decomposition

Let \(H\) be a circulation subgroup of dimension \(r\). Its characters take values in \(\{1,\omega,\omega^2\}\). For each character \(\chi\), the finite Fourier projector \[ \Pi_\chi=|H|^{-1}\sum_{z\in H}\chi(z)^{-1}T_z \] preserves degree and the old quotient. This is the previous sector construction with subgroup \(S=H^\perp/\mathcal B\) in the cut-code quotient, not a new operator. Write \(f=\sum_\chi f_\chi\), \(E_{a,i}=\sum_\eta E_{a,i,\eta}\), and \(w=\sum_\eta w_\eta\) for their quotient components, represented without raising degree. Bounded absorption gives the actual output blocks \[ R_D(E_{a,i}f)_\theta =\sum_\chi R_D(E_{a,i,\theta\chi^{-1}}f_\chi), \qquad R_D(wf)_\theta =\sum_\chi R_D(w_{\theta\chi^{-1}}f_\chi). \] Thus the original problem is a block-matrix kernel problem with coupled input sectors. For general errors, two different input sectors can contribute to the same output block. The existing rank-sum theorem applies when each multiplier is homogeneous up to its prescribed shift; that premise was not established here. Arbitrary block decomposition does not make rank additive.

One sector can lose the useful cancellation

For \(f\) in a single \(H\)-eigenspace, if \(E f\in J_D\), applying \(T_z\) and using its nonzero scalar action on \(f\) shows \((T_zE)f\in J_D\) for every \(z\in H\). Therefore a single-sector solution is subject to the orbit-kernel obstruction, even though no translated error was explicitly adjoined. This is a direct use of the previous proposition, not a stronger obstruction to arbitrary multipliers.

The simplest recorded control is one edge lying on a cycle. Take \(E=x_{e,0}\) and let \(H\) contain its cycle shift. Its translates include \(x_{e,0},x_{e,1},x_{e,2}\), whose sum is one. No nonzero single-sector multiplier can annihilate \(E\) in the permitted window. Yet \(1+x_{e,0}\) survives and annihilates it through degree two. The complete nonlinear version uses a conjunction on independent graph coordinates, legal exact bottom rows, and a parent with a zero prefix; selecting a better parent row makes it easy. Thus this is neither an unavoidable source nor an all-choice obstruction. It does show why projecting an already useful multiplier is not automatically safe, even for a small subgroup.

Averaging is not the missing contraction

Closing the kernel under all translates is already excluded by orbit saturation. Restricting that closure to \(H\) asks for the common kernels of the corresponding error components. On a single sector these are exactly the separate output constraints displayed above. No new rank inequality emerges from their Fourier rewriting. In particular, it does not prove that enough of \(([Ag_ig_jf])_i\) returns to \(C=\operatorname{im}(f\mapsto([Ag_if])_i)\), the quantity the partial-image lemma needs.

The returning-rank counterexample also remains a control against replacing this missing estimate by generic-to-binary specialization with a better universal constant.
