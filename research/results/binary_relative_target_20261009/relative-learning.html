1. Relative ideal membership is sufficient for learning

Let \(\mathcal F\) be an old system over \(\mathbb F_2\) containing all old Boolean equations. Use a one-level affine ENS family with common \(h\ge1\), all companions and fresh Boolean coefficient variables, after zero/unit-span cleanup. Write \(G_b\) for block \(b\)'s input tuple. Suppose an augmented degree-\(D\) PC or NS refutation exists, with \(D\ge2h+1\).

Working extension of common-vanishing learning. If an old polynomial \(f\), of degree \(s\le c\), satisfies

\[ f\in\bigcap_b\mathcal I_c(\mathcal F\cup G_b), \qquad c\ge1, \]

then it is an old-base consequence through

\[ B=TD+s,\qquad T=\max(1,c-1): \quad f\in\mathcal C_B(\mathcal F) \quad\text{or respectively}\quad f\in\mathcal I_B(\mathcal F). \tag{REL-learning} \]

The coefficient-certificate ceiling \(c\) and the actual target degree \(s\) are separate. The earlier \(TD+c\) bound follows by using \(s\le c\).

Proof. By the definition of ordinary NS membership, for every block there are coefficients of degree at most \(c-1\) such that

\[ f-H_b\in\mathcal I_c(\mathcal F),\qquad H_b=\sum_i a_{b,i}g_{b,i}. \]

Set the first coefficient row of every block to \(a_{b,i}\), all other rows to zero, and weight the specialized proof by \(f\). The companion identity is unchanged:

\[ f g_{b,i}(1-H_b) =g_{b,i}\bigl[f(1-f)+f(f-H_b)\bigr]. \]

Its first term has an old Boolean certificate through \(2s+1\), and its second has an old-base certificate through \(c+s+1\). Since \(s\le c\), both fit \(c+s+1\). Fresh field images have certificates through \(2T+s\). The inequalities \(c+1\le3T\le TD\) and \(D\ge3\) put these ceilings within \(TD+s\); old-axiom multiples also fit because \(T\ge1\). Weighted polynomial substitution replays every PC inference through \(TD+s\), ending with \(f\).

For an NS certificate, a companion's original degree is \(e=2h+1\ge3\). Its specialized cofactor costs at most \(T(D-e)\), so the inserted old certificate costs at most \(T(D-e)+c+s+1\le TD+s\), using \(c+1\le Te\). Field terms cost at most \(T(D-2)+2T+s\); an old degree-\(d\) generator costs at most \(T(D-d)+d+s\). This proves the NS statement without closing a truncated NS space under multiplication. All activity and cofactor bounds remain tied to the original degrees.

This uses ordinary membership in each augmented old-input system, not a certificate in the full unrestricted ideal. The earlier target-annihilator theorem has a different, nested-span hypothesis; its supplied annihilator products are not assumed here.

The interface is strictly richer than Boolean vanishing. For the satisfiable old system \(\mathcal F=\{x+yz\}\cup{\rm BOOL}\), take input groups \(\{x\}\) and \(\{y\}\). The affine polynomial \(f=x\) belongs to both degree-two relative ideals, since \(x=(x+yz)+zy\), and is not an old consequence: the old model \(x=y=z=1\) has \(x=1\). The two independent Boolean coordinate groups have no nonzero common affine vanishing class. This illustrates the new membership hypothesis, not an augmented refutation of a satisfiable system.

2. The exact shared-space target for functional PHP

For \(\mathcal F=\mathcal F_N^{\rm fun}\), define

\[ Q_c=\mathcal P_{\le c}/\mathcal I_c(\mathcal F),\qquad A_{b,c}=\mathcal I_c(\mathcal F\cup G_b)/\mathcal I_c(\mathcal F), \qquad R_c=\bigcap_b A_{b,c}\subseteq Q_c. \]

A nonzero class represented by degree \(s\) in \(R_c\), together with \(N\ge2(TD+s)-1\), rules out the augmented refutation: (REL-learning) puts its representative in \(\mathcal C_B(\mathcal F)\), while base filtration stability identifies \(\mathcal C_B\cap\mathcal P_{\le c}\) with \(\mathcal I_c\). The fact \(B\ge c\) follows from \(D\ge3\), \(c\ge1\), and the displayed \(T\).

This is a conditional finite-dimensional criterion. In particular a normalized ordinary design or an input-rank condition alone is not asserted to make \(R_c\) nonzero.

Finite test. Set \(N=11\), \(M=r=6\), and \(c=2\). Each family has 36 affine input linear parts jointly independent modulo the 12 row-sum coefficient vectors, for a combined rank of 48 in 132 old variables. This is the local geometry of the preceding intermediate-rank construction; it is not an instantiated global family on every matching residual.

At \(h=1,\ D=4\), the original companions have degree three and this is beyond the old NS window \(D\le3h\). A shared target of degree \(s\le2\) has \(B=4+s\le6\), satisfying \(N\ge2B-1\). These are legitimate small-instance parameters, not a large-\(n\) logarithmic-accuracy source instance.

The checker uses exact Boolean and same-row/column matching normal forms, then imposes only row-generator multiples by \(1\) and each old variable. There are 7393 matching monomials through degree two; the remaining old NS row span has rank 1398, giving \(\dim Q_2=5995\). Each block adds only its displayed affine generators multiplied by \(1\) and old variables. No derived consequence is multiplied again: these are \(\mathcal I_2\) spaces, not PC closures.

The positive control is an existing pruning mechanism. If \(x,y\) are the selected cells of a collision pair, then

\[ 1=xy+(1-x)+x(1-y) \]

is a degree-two certificate from the old collision equation and the tuple's span. After the prefix basis change, the first two displayed inputs are \(G_0=1-x\) and \(G_1=(1-x)+(1-y)\), so the input part is \(G_0+x(G_0+G_1)\). This reuses the clause-containing pruning theorem; it is not a newly discovered source-family application.

Every cell \(z\) in column zero is also a degree-two consequence of the old base plus each collision tuple: choose a selected cell \(w\ne z\) in that column and use \(z=z(1-w)+zw\). Therefore the common relative space contains the classes of one and all twelve column-zero variables. These thirteen affine classes are independent modulo the old base: affine base consequences are row span, and any nonzero row combination has coefficients outside column zero. The computed dimension thirteen identifies the control's common space exactly with this span.

Each control block's additional NS rank is only 695, although its space contains one; it has not been promoted to the whole 5995-dimensional quotient. This is the required truncated-NS distinction: multiplying a derived degree-two certificate for one would generally raise the NS certificate degree.

Satisfiable encoding control. Omit all column-collision axioms, retaining Boolean and same-row exclusions and the row equations. Put one in column zero of every pigeon row. The extra control inputs were chosen to vanish at that row assignment, and the prefix basis change preserves this. The exact checker verifies all 1596 row-generator multiples and all 4788 input multiples there, obtaining zero, while one evaluates to one. Thus one cannot belong to the corresponding degree-two relative spaces without the column axioms. This control checks the role of the quadratic PHP relations, not just Gaussian-elimination dimensions.

The two full-base fixtures have identical group dimensions and complete joint linear independence modulo rows, yet different relative kernels. Those rank conditions do not determine the quadratic interface.
