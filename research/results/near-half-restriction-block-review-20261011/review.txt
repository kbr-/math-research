Decisive test
- "First step, by hand, at w=1": trivial. If two affine forms lie in Q_1(h), so does their sum, and the constant
  1 cannot (deg h = n > e). So Q_1 is a consistent affine system and always has a common zero. Start at w=2, or
  state this as the lemma.
- "Zero set of a quadratic form with one point removed": this is h = (1+Q) + delta_p, the trivial case
  delta_p + g with deg g = 2 <= e. Common zero p. Replace it.
- "Linear code with one point added": the indicator of a code of dimension k has degree n-k, so this is the same
  trivial case whenever n-k <= e. Require dimension <= D.
- "Union of weight classes": the Trivial cases paragraph already calls this recorded. No untested class remains.
- "It is an equivalent form of properness for the largest system h can certify": false. Emptiness of the common
  zero set of Q_w(h) is necessary only; h need not certify the closure of Q_w(h): the criterion's part (c) asks
  the condition of every element of C_D, including sums with degree falls, and Q_w(h) is not a linear space.
  Say so in outcome one too.
- Q_w(h) contains all polynomials of degree <= w, not only indicators of subspaces. The inclusion of rows and "a
  common zero satisfies every such system" are correct, but outcome one is correspondingly weaker for clause
  systems; state it.
- Outcome two: the direction is right, and it is a ceiling for every length, indeed for all polynomial axioms of
  degree <= w. Quantify c: one fixed c < 1/4 gives a ceiling at (1/4+c)n, which already ends near-half.
- "At w >= D full-width clauses give a trivial yes": should be w >= D+1.
- "Odd weight, that is of degree n": correct. The delta_p + g case is correct (for w <= D).
