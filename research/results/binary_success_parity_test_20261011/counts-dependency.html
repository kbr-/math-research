Coefficient kernel counts

Let \(q\) be a prime power, \(V=\mathbb F_q^k\), and let \(Q\) be a finite-dimensional \(\mathbb F_q\)-space. Fix an \(\mathbb F_q\)-linear subspace \(W\subseteq V\otimes Q\), \(m=\dim W\), before choosing a matrix. For \(Z\subseteq W\), define its input support \[R(Z)=\operatorname{span}\{(\mathrm{id}_V\otimes\lambda)z:z\in Z,\ \lambda\in Q^*\}, \qquad r(Z)=\dim R(Z).\] For \(C\in\mathbb F_q^{h\times k}\), \(h\ge0\), put \(I_C=W\cap(\ker C\otimes Q)\), and let \(N_j(h)\) count matrices with \(\dim I_C=j\). All subspaces and dimensions in this section are over \(\mathbb F_q\).

Lemma (coefficient kernel counts). For \(0\le j\le m\), \[N_j(h)= \sum_{\substack{Z\le W\\ d=\dim Z\ge j}} {d\brack j}_q\,(-1)^{d-j}q^{\binom{d-j}{2}}\, q^{h(k-r(Z))}. \tag{1}\] For counts restricted to full-row-rank matrices, replace the last factor by \[a_h(r(Z))=\prod_{i=0}^{h-1}(q^{k-r(Z)}-q^i), \tag{2}\] with empty product one; if \(h>k-r(Z)\), the product is zero. Proof. The condition \(Z\subseteq I_C\) means that every row of \(C\) annihilates \(R(Z)\). There are \(q^{h(k-r(Z))}\) such matrices. If rows must be independent, choosing them consecutively in the \((k-r(Z))\)-dimensional annihilator gives (2). For either ensemble write this count as \(F(Z)=\sum_{K\ge Z}G(K)\), where \(G(K)\) counts matrices whose intersection is exactly the particular subspace \(K\). Invert on the finite subspace lattice: \[G(K)=\sum_{Z\ge K}\mu(K,Z)F(Z),\qquad \mu(K,Z)=(-1)^{\dim Z-\dim K}q^{\binom{\dim Z-\dim K}{2}}.\] The Möbius formula follows from the Gaussian-binomial identity \(\sum_{i=0}^d{d\brack i}_q(-1)^iq^{\binom i2}=0\) for \(d>0\), and value one at \(d=0\); the product form \(\prod_{i=0}^{d-1}(1-q^i)\) verifies it. Sum \(G(K)\) over all \(j\)-dimensional \(K\). Each \(d\)-dimensional \(Z\) contains \({d\brack j}_q\) such \(K\), giving (1). This also proves the empty-space and zero-row cases. \(\square\)

The coefficients in (1) are ordinary signed integers, not elements of the proof field. Cancellation is essential. Taking absolute values would discard it. In contrast, summing \(q^{\dim I_C}\) over matrices recovers the previous positive rank moment and its bad-choice floor. Formula (1) uses the support of every subspace \(Z\), not only the rank weights of individual tensors.

Identify the actual coefficient code

For \(c\in V^*\), let \(S_c:W\to Q\) be \(z\mapsto(c\otimes\mathrm{id})z\). In chosen bases, transpose these maps to obtain a matrix code \(\mathcal C=\{S_c^{\mathsf T}:c\in V^*\}\). Its dimension is \(r(W)\); the coefficient map has kernel \(R(W)^\perp\). Restricted to a subspace \(Z\le W\), its image dimension is \(r(Z)\). Consequently the integer rank function of this code is exactly \(Z\mapsto r(Z)\), after the standard basis identification with the dual coordinate space. No inner product on the old quotient is required.

The Alfarano–Byrne source, Definition 2.37 and Theorem 4.3, counts tuples of code matrices with prescribed summed column support. A common kernel is the annihilator of that support. In particular, if \[\chi_W(z)=\sum_{Z\le W}\mu(0,Z)z^{r(W)-r(Z)},\] then \[N_0(h)=q^{h(k-r(W))}\chi_W(q^h). \tag{3}\] The prefactor counts the original coefficient lifts; dropping it when the input coordinates are redundant would be wrong. The direct proof above supplies the boundary cases outside the source's standing matrix-size convention. This is the established critical mechanism in our coefficient coordinates, not a new critical theorem.

Nothing identifies a proper quotient of an inconsistent old system with its global Boolean solution set. \(Q,W,S_c\) are finite linear spaces and maps; (1) applies directly to their matrices. Nor does the abstract \(q\)-field formula authorize nonbinary coefficient rows in our source: that application uses \(q=2\).

A paid prefix criterion

Use a binary degree-\(D\) pseudoideal containing old Booleanity, a weight \(w\) of degree at most \(b\), a fixed binary linear domain \(U\subseteq V_K\) with \(H=\dim[wU]>0\), and \(M\) fixed distinct blocks. Their binary prefixes \(P_a\) have safe degree charges at most \(p_0\), their input tuples have degree at most \(\delta\ge1\), and each has \(h\ge1\) legal rows remaining. Their coefficient grids are fresh and independent; shared occurrences of a block receive one matrix. Earlier choices are fixed, so selecting these rows changes no other tuple in this batch. Proof. Positive count chooses one matrix \(C_a\) for each distinct block. Expanding its prefix \(R_a=\prod_{j\le h}(1-\sum_i C_{a,ji}g_{a,i})\) shows that every actual tuple \(([wP_aR_ag_{a,i}f])_i\) lies in \(W_a\). Its contraction by row \(j\) is zero: it is \[wP_af(q_j-q_j^2)\prod_{\ell\ne j}(1-q_\ell),\] a Boolean consequence through (4). Thus the actual block error image lies in \(I_{a,C_a}\) and has dimension at most \(j_a\). All these maps factor through the same \([wU]\) by absorption. The previous direction control is now distinguished

Reuse the recorded full Boolean-space control on \(k\ge2\) bits, with tuples \(g=(x_1,\ldots,x_k)\) and \(g'=(s,x_2,\ldots,x_k)\), \(s=1+\prod_i(1+x_i)\). Both multiplication images have dimension \(m=2^k-1\), identical complete block-shortening data and the same uniform mean. For one row, the first tuple has \(N_0(1)=0\), while the second has \(N_0(1)=1\): only the row selecting \(s\) avoids every nonzero input pattern.

Indeed write a nonzero row as \((c_1,c')\), and \(a=2^{k-1}\). For the nonlinear tuple, the zero row leaves dimension \(2a-1\); the row \((1,0)\) leaves zero; the \(a-1\) rows with \(c_1=0,c'\ne0\) leave \(a-1\); and the \(a-1\) rows with \(c_1=1,c'\ne0\) leave \(a\). This follows by counting the two choices of \(x_1\) over each nonzero tail and the single nonzero point over the zero tail. For the linear tuple, every nonzero row leaves \(a-1\). These are all-parameter evaluations of the existing example, not a new hard-source family.

The positive cardinality moment cannot certify the nonlinear tuple's zero intersection: even conditioned on nonzero rows it is \[\frac{1+3(a-1)2^{a-1}}{2a-1}>2 \quad(a\ge2).\] For four copies, even the independent-row expected-dimension sum is \(4(a-1)\ge2^k\), the full weight dimension, while their exact good choices all give zero. Equal-span and explicit-selector methods already handle these copies; this control tests the count's information, not new source coverage. The base here is satisfiable and the multiplier domain is full.

A hard-quotient positivity control

Corollary (clause critical positivity). Over any finite field, let a degree-\(D\) pseudoideal contain a positive-clause polynomial \(G=\prod_{i\in S}(1-x_i)\), where \(t=|S|\ge1\). Let \(\deg A\le a\), and use the raw-variable multiplication image \[W=\{([Ax_if])_{i=1}^n:f\in V_L\}.\] If \(a+L+t\le D\) and \(h\ge t\), then \(N_0(h)>0\): choose rows selecting the \(t\) coordinates in \(S\), and pad by zeros.

Proof. If \(z=([Ax_if])_i\in I_C\), then \(Ax_if\in J_D\) for \(i\in S\). The literal telescoping identity \[1-G=\sum_{i\in S}x_i\prod_{\text{earlier }j\in S}(1-x_j)\] puts \(Af(1-G)\) in \(J_D\) through \(a+L+t\). Old membership of \(G\) also puts \(AfG\) there. Thus \(Af\in J_D\); multiplying by any \(x_i\) fits \(a+L+1\le D\), giving \(z=0\). The selected coefficient matrix therefore has zero intersection. \(\square\)

For an unsatisfiable canonical CNF with a proper old window, a positive nonempty clause exists because the all-zero assignment violates a clause, and an empty clause would already give one in the pseudoideal. If its original width bound is \(d\ge2\), \(A\notin J_D\), \(L=K+h\), \(K\ge d-1\), and the displayed reserve holds, wide terminal fiber still forces every complete flag's scalar-intersection upper expression for this same selected matrix to be at least \(K+2-d>0\). Yet \(I_C=0\). In this binary application the positivity count can therefore recognize a choice that this flag relaxation misses, on an actual proper hard quotient. The original input-word companion budget and any full source replay must also fit; the usual raw-input row charge \(2h+1\) is not replaced by \(t\). This sharpens the recorded positive-clause control's intersection statement, not the hardness of the raw-variable block, which was already known to be easily removable.
