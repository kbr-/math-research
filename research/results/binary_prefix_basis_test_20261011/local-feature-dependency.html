Write \(V_k\) for old polynomials of total degree at most \(k\), and brackets for classes modulo \(J_D\) whenever the displayed degrees fit. Let \(w\notin J_D\), \(\deg w\le b\), and put \(H_w(k)=\dim[wV_k]\). There are finitely many nonempty actual tuples \(g_{a,i}\), with degrees at most \(\delta_a\ge1\), and original positive row counts \(h_a\).

For each tuple choose \(q_a\ge0\) old features \(z_{a,j}\) of degree at most \(d_a\), where \(1\le d_a\le\delta_a\). Define \(\psi_a(x)=x,\psi_a(Z_j)=z_{a,j}\). Which local rank is relevant?

There is a canonical available dictionary, although no small-size bound is claimed. Let \(\mathcal A_w=[wV_1]\) and set \[ q_a=\dim\bigl((\mathcal A_w+\operatorname{span}_i[wg_{a,i}])/\mathcal A_w\bigr). \tag{5} \] Choose a basis of this quotient from the original input classes and use those actual inputs as features, with \(d_a=\delta_a\). Linear algebra gives (1), with an old-affine reference part. The feature representatives are actual old polynomials, not free quotient symbols. If \(q_a=0\), choose no features and \(d_a=1\); the actual comparison still pays \(\delta_a\). This recovers the existing weighted affine-reference mechanism rather than treating it as new.

The elementary bound (4) gives a useful conditional calibration. Suppose \(D=\Theta(n)\), \(b\le D/8\), all \(d_a,\delta_a\le d=O(\log n)\), \(M\le n^A\), and \(q_a\le q=o(n/\log^2 n)\). With \(K=\min(n,\lfloor D/(16d)\rfloor)\), \(\eta_a\ge K/(4(n+q))=\Omega(1/d)\). Thus \(t_a=t=O(d(q+\log(2M)))\) suffices for \(M2^q(1-\min\eta_a)^t<1\). Both (2) fit, because \(td=O(d^2(q+\log(2M)))=o(n)\). With common \(h\), coefficient degrees obey \(T\le1+O(d^2(q+\log(2M))/h)\). A complete application must still verify \(TB=o(n)\), earlier maps and identities, and the original source degrees. There is no claim that arbitrary compiler tuples satisfy (5) with this \(q\).
