For v != 0 define n_a(v)=#{c_a:E_a(c_a)v=0}. Counting pairs of a global choice
and a nonzero successful vector in two orders gives the exact integer identity

 sum_C (2^(dim intersection_a ker E_a(C_a))-1)
   = sum_(v in V minus {0}) product_a n_a(v).

Proof: both sides count precisely {(C,v):v!=0 and all E_a(C_a)v=0}. For fixed v,
the choices factor by block. This is ordinary finite-set counting, not rank
independence after the weight is allowed to vary. Positivity is exactly the
existence of a common v with every n_a(v)>0, so no new existence theorem follows.
The two-domain discussion in cor:parameter-grid-dependence already states the
same distinction. No new claim registration is proposed for this rearrangement.

The one-row equation can be made explicit. For a fixed representative f of v,
fixed prefix P_a and inputs g_ai, set z_a(v)=([wP_a g_ai f])_i. A constant row
c must solve
 z_a(v)=sum_j c_j ([wP_a g_ai g_aj f])_i.
For freely varying binary row bits, the number of solutions is zero if z_a(v)
is outside the displayed column span; otherwise it is 2^(number of row
coefficients minus the binary column rank). A restricted finite parameter family
instead counts its intersection with this affine solution set.
This is the elementary affine linear-system count, not a supplied source bound.
For polynomial coefficients sum_t c_jt phi_t(x), replace g_aj by phi_t g_aj and
pay its degree. The existing feature-row theorem already makes this replacement.
No independent input or free low-degree feature is introduced.
