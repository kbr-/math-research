# Short multiplicity preprint — revision 1

The editable sources, final PDF, build instructions and review scope are in
[the publication directory](../../../publications/binary-polynomial-multiplicity/README.md).

This directory retains the three complete final pdflatex pass logs, raw extracted
text, font inventory, PDF metadata, and `pdf-check.json`. `verify_pdf.py` repeats
the automated text/geometry/raster checks against the current publication PDF;
run it through `compute.sh`. Temporary PNGs are not published. The QA script uses
already installed Poppler and Pillow and installs nothing. Re-running it replaces
these reports, so preserve a dated snapshot for later revisions.

The earlier failed parser checks and the initial bibliography-spacing build are
preserved in the timing-session archive. No mathematical computation or Lean
replay was needed; this draft presents the already recorded short deduction.
