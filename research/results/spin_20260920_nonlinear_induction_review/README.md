# Low-cubic-rank source endpoint

The [notebook proof](https://kbr.is-a.dev/math-research/#entry-2026-09-20-low-cubic-rank-source)
generalizes the existing finite-partition coefficient map to polynomial branch
inputs, keeping every companion and coefficient field equation at a proved
multiple of its original degree. Applying an imported Haramaty–Shpilka
input-space lemma gives a complete quadratic image for cubic spaces with
uniform rank O(log log n). The finite quadratic theorem is checked against
the resulting quasipolynomial branch inventory, rather than assuming a
polynomial number of branches.

Inputs remain old-only. The condition concerns every linear combination in
each input space; it is not a test only of the displayed generators. The
unrestricted high-rank case and a relative endpoint for retained deeper
coefficients remain open. No new finite enumeration was required. Source
proofs are imported dependencies, and metadata validation is not mathematical
proof checking.

The exact retrieved source has two distinct visible dates; source-audit.json
records them and the reading coverage, while source-provenance.json records
the unchanged local file hash. Full source text is not redistributed.
