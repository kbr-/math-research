from this cycle. They did not certify the complete triple-triple module.

errors. Some prototypes import helpers by their original `research/tools/` paths;
restore those paths from this directory if reproducing a failed attempt. Earlier
transient zero-test/matrix-copy fixes are described in the dated record; this is
not a claim that every intermediate edited version was snapshotted.
