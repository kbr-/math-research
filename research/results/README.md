# Persistent computation results

Store complete research outputs here, including large tables, enumerations,
matrices, and certificates. Use meaningful run subdirectories and an explicit
`--out` option in the generating script. These files are intended to be tracked
and committed with their research results, not ignored as scratch data.

Reference each output in the notebook/research log and retain its generating
command, parameters, seed if used, encoding/schema, and relevant checks. Preserve
earlier accepted runs. Stream large files within the computation memory budget.
