Normalized pivot mask

Lemma. Work over \(\mathbb F_2\), with \(m>n\ge1\), \(A\) of shape \(m\times n\), \(B\) of shape \(n\times m\), \[ F_{ik}=\delta_{ik}+\sum_lA_{il}B_{lk},\qquad P=\prod_{i,k}(1+F_{ik}),\qquad P_{ik}=\prod_{(a,b)\ne(i,k)}(1+F_{ab}). \] Let \(C=\sum c_{ik}Y_{ik}+\sum d_xZ_x\) be any Hilbert-like certificate for these equations and all entry Boolean axioms \(b_x=x^2+x\). Fix \[ K_{F_{ik}}=\sum_l(B_{lk}Z_{A_{il}}+A_{il}^2Z_{B_{lk}}),\qquad Q=\sum_{i,k}c_{ik}P_{ik}K_{F_{ik}}+P\sum_xd_xZ_x. \] This is the direct normalization \(Q(x,b(x))=P(x)\). Set \(j=n+1\). Let \(\rho_x\) set column \(j\) of \(B\) to zero and row \(j\) of \(A\) to \(e_1\). Extend it to \(\rho\) by setting \(Z_{B_{1j}}=1\) and every other \(Z\) to zero. Then \[ \rho(Q)=\rho_x(c_{jj})R,\qquad R=\rho_x(P_{jj}). \] This restriction has no size or depth overhead. The mask \(R\) is nonzero formally, Boolean-zero, and has the smaller-residual decomposition below with polynomial-size constant-depth correction circuits.

Isolation proof. Each summand of the displayed \(K\) specializes to \(B_{lk}(A_{il}^2+A_{il})+A_{il}^2(B_{lk}^2+B_{lk})=(A_{il}B_{lk})^2+A_{il}B_{lk}\), so it is the stated complete field-defect witness. Under \(\rho_x\), the diagonal factor \(1+F_{jj}\) is zero. Thus \(P\) and every \(P_{ik}\) other than \(P_{jj}\) vanish. The remaining witness specializes to \(A_{j1}^2=1\). This proves the restriction identity independently of the syntax of a circuit computing \(C\).

For the canonical shared-pivot certificate, \(c_{jj}\) depends only on the first \(n\) rows of \(A\), so \(\rho_x\) leaves it unchanged. Its Boolean function is determinant, hence the polynomial is nonzero. Every diagonal factor remaining in \(R\) is a nonzero bilinear sum and every off-diagonal factor has constant term one. Their polynomial ring is an integral domain, so \(R\ne0\) and \(c_{jj}R\ne0\). Complete formal cancellation of this probe is excluded for this fixed representative. No circuit lower bound for the product follows.

Complete mask decomposition. Let \(I=\{1,\ldots,m\}\setminus\{j\}\), \(t_k=B_{1k}\) for \(k\in I\), and put \[ T=\prod_{k\in I}(1+t_k),\quad H=\prod_{i,k\in I}h_{ik},\quad h_{ik}=1+\delta_{ik}+\sum_{l=1}^nA_{il}B_{lk}. \] The remaining row-\(j\) factors give \(R=TH\); all column-\(j\) off-diagonal factors are one. Set \(t=0\). Then \(H_0=P'\) is exactly the rank residual on matrices of shape \((m-1)\times(n-1)\) and \((n-1)\times(m-1)\), with the same order on the surviving outer labels. Order the factors \(h_a\), and write \(h_a^0=h_a|_{t=0}\). Literal telescoping gives \[ H+H_0=\sum_a(h_a+h_a^0)\prod_{ba}h_b^0 =\sum_{k\in I}t_kL_k, \quad L_k=\sum_{i\in I}A_{i1}\prod_{b<(i,k)}h_b\prod_{b>(i,k)}h_b^0. \] Multiplying by \(T\) yields the full Boolean correction \[ R=TP'+\sum_{k\in I}\left(\prod_{\substack{r\in I\\r\ne k}}(1+t_r)\right)L_k(t_k^2+t_k). \] All factors are explicit degree-at-most-two expressions; the displayed sums and products have jointly polynomial gate/wire size in \(m,n\) and absolute constant depth. There is no division or high-component extraction. Multiplying this identity by \(c_{jj}\) retains that coefficient's actual cost.

On Boolean inputs, either \(T=0\), or every \(t_k=0\). In the latter case \(H=P'\), which is zero: rank \(m-1\) cannot be achieved with inner dimension \(n-1\). Hence \(R\) is Boolean-zero even at \(m=n+1\). It is not a nonzero Boolean scalar that can be inverted to expose determinant.

Erase the chosen coefficient using the existing lemma. The variable-only map \(\rho_x\) is a coordinate retraction and \(\rho_x(F_{jj})=1\). Index this generator as \(G_0\) and include every other matrix and Boolean generator among \(G_i\), writing \(C=\sum_ic_iU_i\). For \(i>0\), set \(h_i=\rho_x(c_i)\) and \[ c'_i=c_i+h_iG_0,\qquad c'_0=c_0+\sum_{i>0}h_iG_i. \] The added terms cancel in \(\sum_ic'_iG_i=1\). Moreover \(\rho_x(c'_i)=0\) for \(i>0\), and applying \(\rho_x\) to the original identity gives \(\rho_x(c'_0)=1\). The proved unit-slice circuit construction realizes this with polynomial overhead and depth at most \(\max(d,2)+4\) from a size-\(S\), depth-\(d\) circuit for \(C\). Its direct normalization therefore has \(\rho(Q')=R\). This removes determinant dependence from this probe, including all Boolean coefficients; it constructs no shallow global certificate from nothing. The following normalization adds only constant depth. \(\square\)

Nonvacuity. The previous cycle constructs \(C\) for every \(m=2n\), \(n\ge1\), so the certificate premise has unbounded witnesses of polynomial description. At \(n=1,m=2\), write the surviving top row entry as \(a\) and surviving \(B\) entry as \(t\). Then \(R=at(1+t)=a(t^2+t)\ne0\) formally, \(P'=0\), and the exact Boolean correction supplies the entire mask.

Degenerate cases. For all \(n=1,m>1\), the child inner dimension is zero, so \(P'=0\). For \(n\ge2\) it is a nonzero formal rank residual but zero on the Boolean cube. The case \(m=n+1\) is covered, not excluded by a large deficit. For \(m\le n\), the refutation premise is unavailable; local telescoping remains an identity, but Boolean vanishing is not asserted from the same rank inequality. The \(n=0\) base belongs to the preceding theorem and is not part of this lemma.
