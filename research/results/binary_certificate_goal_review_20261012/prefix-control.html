Input padding in the exact prefix image

Lemma (prefix image padding). Fix the local certificate choices and factor orders in the binary DAG prefix simulation. Let a proof \(\pi\) of symbol size \(S\) translate to certificate polynomial \(C_\pi\). Its original ordered clause-falsity tuple is \(F_1,\ldots,F_m\), of total formula size \(s\). For each integer \(t\ge1\), prepend \(t\) ordered copies of that input list as unused input occurrences. Retain the original proof and all its premise edges. Proof. The new input occurrences have exactly the fixed literal orders of \(F_i\), so their correction terms are zero. The first copy contributes \(H\), the next \(PH\), and the \(j\)-th contributes \(P^{j-1}H\). For every old input or local correction term, its old prefix gains the left factor \(P^t\). For an old premise \(L_j\) used at line \(i\), the simulation writes the prefix as \(U(1-L_j)V\). Every new line precedes \(j\), so the new \(U\) is \(P^tU\), while \(V\), the old multiplier \(a\), and \(L_j\) are unchanged. The absorption certificates \[ -U(L_j^2-L_j)Vab+U(1-L_j)[Va,L_j]b \] therefore acquire exactly the same left factor \(P^t\), with the same local Boolean and commutator certificates as before. Summing proves the polynomial identity without changing those certificate choices. Only \(tm\) legal input occurrences are added; no earlier subtree is duplicated. The existing jet argument applies because the input CNF has no common Boolean zero, so \(P(a)=0\). No new calculus rule or semantic substitution is involved. \(\square\)

Terminal padding is different. Once an empty cedent \(L_T=1\) occurs, the later prefix contains the literal zero \(1-L_T\). Later input and correction terms vanish. In a premise absorption, that zero lies in \(U\) or \(V\), unless the premise is \(L_T=1\), whose Booleanity and commutator certificates are zero. The standard recursive certificates respect these zero factors. Thus an appendage after the old empty cedent contributes zero in this prefix construction. The tree-like recursive simulation's final-cut realization cannot be substituted for this different compiler.

Nonvacuity. A cut on contradictory unit inputs gives a proof to which arbitrarily many unused input rounds may be prepended. Their first-violation prefix polynomial is explicit. Degenerate cases. A unit input makes \(P=0\); a zero input contributes its own placeholder but does not change \(P\). Repeated occurrences keep their original generator labels. Without a refutation no certificate is constructed. Polynomially growing \(t\) has polynomial proof overhead, but pruning the unused new nodes returns the original proof and need not retain any erasure.
