Contract only the part that has a low-degree representative

Work over any field \(F\) of characteristic \(p\). Let \(J\subseteq F[x]_{\le D}\) be a degree-\(D\) pseudoideal, \(\deg A\le a\), \(\deg g_i\le\delta\), and \(g_i^p-g_i\in J\), with \(\delta\ge1\). Let \(U\subseteq F[x]_{\le K}\) be any finite-dimensional \(F\)-subspace and assume \[ a+K+(p+1)\delta\le D. \] Put \(Q=F[x]_{\le D}/J\), \(Y=Q^s\), and \[ T:U\longrightarrow Y,\quad Tf=([Ag_if])_i,\qquad C=\operatorname{im}T,\quad c=\dim C, \] \[ M_jf=([Ag_ig_jf])_i,\qquad M(\lambda)=\sum_j\lambda_jM_j,\qquad e=\operatorname{rank}_{F(\lambda)} \bigl(U_{F(\lambda)}\xrightarrow{M(\lambda)}Y_{F(\lambda)} \longrightarrow (Y/C)_{F(\lambda)}\bigr). \] The number \(e\) measures the multiplied image outside the current allowed image. It is a generic matrix-pencil rank, not an asserted bound on it.

Lemma (partial image contraction). There is a prime-field coefficient choice \(q=\sum_j t_jg_j\), \(t_j\in\mathbb F_p\), for which the new error-map rank on the same \(U\), with prefactor \(A'=A(1-q^{p-1})\), is at most \[ c'\le\min\{c,\ c/p+e\}. \] More generally, for finitely many subspaces \(U_\nu\), all within their stated ceilings with the same \(A,g,J\), and nonnegative real weights \(\alpha_\nu\), one choice \(q\) satisfies \[ \sum_\nu\alpha_\nu c'_\nu \le\sum_\nu\alpha_\nu\min\{c_\nu,\ c_\nu/p+e_\nu\}. \] This is a simultaneous weighted objective, not a separate inequality for every \(\nu\).

Proof. The preceding generic-rank argument applies on the arbitrary domain \(U\): the stacked \(M_j\) has the same kernel as \(T\), and formal Frobenius compression gives \(\operatorname{rank}M(\lambda)=c\). The higher ceiling here is exactly the compression cost for the prefactors \(Ag_i\) and domain degree \(K\). Rank specialization over the prime-field grid gives \(\mathbb E_q\operatorname{rank}M(q)\ge(1-1/p)c\). Every specialized rank modulo \(C\) is at most its generic rank \(e\). Therefore \[ \mathbb E_q\dim(\operatorname{im}M(q)\cap C) =\mathbb E_q\bigl(\operatorname{rank}M(q) -\operatorname{rank}(\pi M(q))\bigr) \ge(1-1/p)c-e. \]

For a vector in this intersection choose \(f,r\in U\) with \(Tr=M(q)f\). For every coordinate, \(Ag_i(r-qf)\in J\), through ordinary degree at most \(a+K+2\delta\). Multiply that relation by \(1-q^{p-1}\). Also \[ Ag_if(q-q^p)\in J \] by the supplied Frobenius identities. Both products fit \(a+K+(p+1)\delta\le D\). Adding shows \(A'g_ir\in J\) for every \(i\). Thus every intersection vector has a lift in the new kernel. The old kernel is also contained in the new one by absorption. It follows that \[ c'\le c-\dim(\operatorname{im}M(q)\cap C). \] Average, using also the pointwise \(c'\le c\), to get \(\mathbb E_q c'\le\min(c,c/p+e)\). One choice achieves this upper bound. Linearity of expectation gives the weighted-objective assertion for the same common random coefficients. \(\square\)

No multiplication closure of \(U\) is assumed. The low-degree representative \(r\) is needed only modulo the current stacked error map, not literally as \(qf\), and only for the intersecting image. In a conditioned application, choose \(U\) to satisfy all earlier errors; then \(r\in U\) preserves those conditions. No actual source certificate has been compressed. Its original cofactor costs must still fit when the lemma is used in a complete contradiction.

This differs from bounding an enlarged image by a flag and from asserting a full invariant space. The chosen-prefix comparison and factor normalization already demonstrate why one should retain actual coefficient choices and certified smaller representatives. The new rank bound still needs an estimate of \(e/c\); merely computing its definition would leave the goal untouched.

A general control: several useful rows can precede the first rank drop

Proposition (prefix escape plateau). Over \(\mathbb F_2\), take \(m\ge1\) nonempty disjoint Boolean blocks of equal size \(d\ge1\), with block conjunctions \(z_1,\ldots,z_m\). Let \(B\) be any binary \(t\)-by-\(m\) matrix and \[ P_B=\prod_{\ell=1}^t(1+(Bz)_\ell),\qquad h=m-\operatorname{rank}B. \] Use \(A=P_B\), \(g=z\), \(U=\langle1\rangle\), \(K=0\), and the Boolean vanishing pseudoideal through \(D\ge(t+3)d\). Then \[ c=\begin{cases}1&h\ge1,\\0&h=0,\end{cases}\qquad e=\begin{cases}1&h\ge2,\\0&h\le1.\end{cases} \] If \(h\ge2\), every additional legal row leaves the zero-cutoff rank equal to one. If \(h=1\), exactly half the rows kill it and half leave it equal to one.

Proof. The map from old Boolean assignments to \(z\in\mathbb F_2^m\) is surjective because the blocks are nonempty and disjoint. The error vector \(P_Bz\) is supported on \(\ker B\setminus\{0\}\) and is nonzero there. A map from the one-dimensional \(U\) therefore has rank one exactly when \(h>0\), for \(d\ge2\), recovering the \(K=0\) instance of the existing exact monomial-code formula.

When \(h=1\), the support has one \(z\)-value \(y\ne0\); multiplication by any \(q=\sum_j\lambda_j z_j\) acts on the entire error vector by the scalar \(q(y)\). Hence the generic image lies in \(C\) and \(e=0\). When \(h\ge2\), choose two distinct nonzero \(y,y'\in\ker B\). Their generic linear-form values differ, since \(\sum_j\lambda_j(y_j-y'_j)\ne0\). Thus the multiplied error vector cannot be a scalar multiple of \(P_Bz\); its image modulo the one-dimensional \(C\) has rank one. This proves the formula for \(e\). For \(h=0\) both maps vanish.

Adding one row reduces \(h\) by at most one. It therefore leaves some nonzero kernel vector when \(h\ge2\), proving the rank plateau for every choice of the new row. When \(h=1\), the nonzero \(y\) is excluded exactly when the new row has dot product one with \(y\), which occurs for half of all rows. The products and Boolean reductions use the stated original ceiling, including dependent or zero rows; no reduced product degree is substituted for it. \(\square\)

The direct argument also covers \(d=1\), outside that older theorem\'s stated nonlinear-block range. Equal block sizes are retained to match its setup and simplify the original degree ledger; the linear-algebra calculation does not depend on equality of those sizes.

The partial-image bound gives no decrease on the plateau: \(\min(1,1/2+1)=1\). At \(h=1\) it gives expected rank at most \(1/2\), exactly the computed average. The actual rank plateau was already present in the monomial-code theorem; it is not a new obstruction to coded batches. In particular, requiring every useful row to decrease this particular rank would incorrectly reject a batch whose final rows kill all errors. This is a satisfiable Boolean control, not an unavoidable family of gates in a hard refutation.
