Ordinary PHP has pigeon clauses \(\bigvee_j X_{ij}\) and hole clauses \(\neg X_{ij}\lor\neg X_{i\prime j}\); functionality additionally forbids two occupied cells in a row. The first target is: for every fixed odd prime \(p\) and real \(K>0\), sufficiently large \(N\) require more than \(N^K\) proof lines in the audited standard DAG calculus. Source convention

Part–Tzameret, revision 2, Section 3, pp. 14–15 defines lines as disjunctions of affine equations, with duplicate disjuncts contracted. From \(C\vee(f=0)\) and \(D\vee(g=0)\), resolution derives \(C\vee D\vee(\alpha f+\beta g=0)\). Weakening adds an equation; simplification deletes a false nonzero constant equation. Boolean axioms are \((x_i=0)\vee(x_i=1)\). The source counts total written size, not just lines. Its stronger semantic systems are distinguished from this syntactic calculus.

Accordingly, the branch keeps its stronger proof-line objective but must prove its own registry-inventory accounting. A lower bound only in written size would not establish that objective. Standard syntactic steps, not unrestricted Boolean-semantic consequence, are the initial target.

Recovered dependencies and falsification attempt

The 14 September disequality calculus already has a complete all-prime rule simulation. Its clause is \(\bigvee_i(g_i\ne0)\), so its falsifying set is an affine flat. Its \(p\)-way split has height-independent PC cost \(4h+p-1\), with all coefficient equations \(r^p-r\) retained. Rebuilding this split would not fill the equation-clause gap.

The same earlier entry contains the exact full-field conversion obstruction: \(\bigvee_{i=1}^w(y_i=0)\) needs \((p-1)^w\) affine-disequality CNF clauses in the same unrestricted coordinates. Its falsifying set is the nonzero box. Every affine subspace contained in that box is a point, since any nonconstant coordinate takes zero somewhere. Exact CNF conversion must cover all box points by these falsifying flats. Thus a blanket polynomial full-field conversion is already refuted by an inherited result. This is a rediscovered applicability boundary, not a new theorem.

The restriction to unrestricted field coordinates is essential. Boolean domains and extra variables change the representation problem, so this obstruction alone cannot rule out domain-aware proof translations. The binary basis compression preserves a common zero set; it cannot simply be applied to a union of equation hyperplanes at odd primes. Existing graph restriction still makes the initial clauses short, but does not bound intermediate equation-clause width.
