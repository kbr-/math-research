# Cubic branch-budget refinement

The [notebook proof](https://kbr.is-a.dev/math-research/#entry-2026-09-20-cubic-branch-budget-refinement)
checks the finite quadratic endpoint with selector degree and log branch inventory
of order n^epsilon for every fixed epsilon<1/13. It derives a larger sufficient
cubic-rank range, c_* log n for a small absolute constant, using the unchanged
common-feature construction. The high-rank structural extraction remains open.

The independent-triple count is kept distinct from cubic rank. Its displayed
head-count requirement belongs to that sufficient estimate, not every possible
construction. The literature screens in source-screens.json were orientation,
not imported quantitative theorems. No new numerical computation was necessary.
