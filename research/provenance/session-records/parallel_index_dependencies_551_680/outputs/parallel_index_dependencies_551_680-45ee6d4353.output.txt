### 580 obs:quadratic-sum-flat-span-obstruction

 The failure persists for an arbitrarily large input span. Take \(q_i=a_ib_i+c_id_i\) on disjoint four-variable groups. In a nonzero sum of \(t\) such inputs, each group has bias \(1/4\), so the support on those \(4t\) variables has size
