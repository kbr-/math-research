1. Charges may move under restrictions

Theorem (charged character space). In the graph and Fourier encoding of the character theorem, allow any charge vector \(c\in\mathbb F_3^{V(G)}\). For \(\max(4,2\Delta)\le D<\varepsilon n/8\), replace the phase condition by \[\omega^a m_\alpha\sim_c\omega^b m_\beta \iff \alpha-\beta=\partial s,\quad |\operatorname{supp}s|<n/2,\quad c\cdot s=b-a.\] Its kernel is again a proper degree-\(D\) pseudo-ideal containing the charged Fourier axioms. Thus the corresponding one-hot Boolean system has no PC refutation at a degree \(B\) with \(\max(B,4,2\Delta)<\varepsilon n/8\), over either \(\mathbb F_2\) or \(\mathbb F_4\). Nonzero total charge makes the system inconsistent; neither equal charges nor a congruence condition on \(n\) is required.

Proof. A relation witness has support at most \(2D/\varepsilon<n/4\), exactly as before. Reflexivity and symmetry hold, and adding two witnesses proves transitivity since their support union has size below \(n/2\) and \(c\cdot(s+t)=c\cdot s+c\cdot t\). A scalar cycle has \(\partial s=0\); connectedness and the small support condition force \(s=0\), so the scalar phase is zero. Consequently class reduction has nonzero value on one. Canceling within each coordinate class expresses a kernel polynomial as differences on its own monomial support; multiplying them by a variable preserves the exponent difference and the phase \(c\cdot s\) within the ceiling. This proves pseudo-ideal closure as in the original argument. The vertex axiom at \(v\) uses witness \(s=\mathbf1_v\), whose phase is \(c_v\); the domain axioms reduce to zero. The explicit Fourier transfer supplies the displayed Boolean degree ceiling. A binary proof is also a proof over \(\mathbb F_4\). Finally summing all vertex charge equations on edge labels cancels each oriented edge twice with opposite signs; a nonzero total charge is inconsistent. \(\square\)

The lower constant cutoff retains the earlier cubic/domain comparison convention; it is not optimized. This is the same binomial proof with a different linear phase functional, not a new lower-bound method.

2. Delete low-incidence support, not proof lines

Let \(T\subseteq E(G)\) have maximum incident degree \(a\), with \(a<\varepsilon\). Fix any labels \(\eta_e\in\mathbb F_3\) on its edges. Set their one-hot indicators to the corresponding constants and retain the other edge variables. Let \(G'=G\setminus T\), and put \[c'_v=c_v-\sum_{e\in T,\ e\ni v}\sigma_{ve}\eta_e.\] Then \(\sum_vc'_v=\sum_vc_v\). For every \(S\) of size at most \(n/2\), \[|\delta_{G'}S|\ge|\delta_GS|-a|S|\ge(\varepsilon-a)|S|.\] In particular \(G'\) remains connected and expanding. Each old forbidden-tuple axiom maps either to zero or to the corresponding forbidden-tuple axiom for \(c'\). Row, Boolean and exclusion axioms on fixed edges map to zero; the others remain. The same holds for the exactly-one CNF encoding.

Theorem (localized source transfer). Augment the binary one-hot system \(\Gamma(G,c)\) by any finite ordered family of complete binary ENS blocks of positive accuracy: \[P_b=\prod_{u=1}^{h_b}\left(1-\sum_i r_{b,u,i}g_{b,i}\right),\qquad h_b\ge1,\] including every \(g_{b,i}P_b\) and every fresh Boolean domain equation. Assume each input polynomial uses only old indicators on \(T\) and earlier coefficient variables; arbitrary dependence and degree within that support are allowed. Every degree-\(B\) PC refutation of this augmented system specializes to a degree-at-most-\(B\) PC refutation of \(\Gamma(G',c')\). Hence there is no such refutation if \(\sum c_v\ne0\) and \[\max(B,4,2\Delta)<(\varepsilon-a)n/8.\] The same exclusion holds for ordinary NS certificates at that degree. No bound on block inventory or depth is needed within the stated support class.

Proof. After fixing the old labels, assign fresh coefficients in order. Every current input is now a binary constant because its old and earlier variables have been assigned. If every input is zero, assign all current coefficients zero; every companion is zero. Otherwise choose one input equal to one, set its coefficient in the first row to one, and set all other current coefficients zero. That row's factor vanishes, so \(P_b=0\) and every companion is zero. All fresh domain equations vanish. Empty tuples cause no difficulty; positive accuracy is needed for the nonzero-tuple case.

This defines a single constant substitution for the complete family, not different assignments for different companions. Its old axiom images were described above. Apply it line by line to a PC proof: multiplication by an assigned variable is scalar multiplication, while multiplication by a remaining variable is unchanged. Constants do not raise degree, so the final one yields the asserted residual proof. Apply the charged-character degree barrier to \(G'\), whose maximum degree is at most \(\Delta\). An NS certificate is a PC derivation through its original degree, or can be specialized directly. \(\square\)

3. The complete matching error tuple

For a matching \(M\), take \(a=1\) and \(\varepsilon>1\). For old inputs \(x_e=\ell_{e,0}\), fix every matching edge to label 1. Then every \(x_e\) becomes zero. Consequently \[P_\nu x_e\longmapsto0\qquad(e\in M)\] for every approximator \(P_\nu\), including any prescribed parity-check matrix and all companions at once. The image of \(P_\nu\) itself need not vanish. This settles the specified complete matching tuple by a restriction, without expanding a single product or requiring a new common weight. If later complete helpers also have all old support in \(M\), the sequential constant construction handles them as well.

The residual charges need not be equal, which is why the preceding generalization was included. Their total remains nonzero. The degree margin is \((\varepsilon-1)n/8\), after the displayed fixed encoding cutoff, regardless of how many matching-supported blocks there were. This does not compute their ranks in the original \(J_D\): it transfers the entire proof to a different certified old system.

Scope test. A block reading every graph edge can have old-support degree \(\Delta\). Expansion cannot exceed \(\Delta\), so the needed \(a<\varepsilon\) is unavailable.
