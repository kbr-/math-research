Conditional transport of the actual defects

For the lines \(A,A\to B,B,B\to C,C\), write their falsity values as \(a,b,u,c,v\), respectively. Their semantic defects are \[ R_1=b-(1-a)u,\qquad R_2=c-(1-u)v. \] The following identity is literal over any field: \[ T=(1-a)R_2+vR_1=(1-a)c-(1-a)v+vb. \] It removes \(u\), but its coefficient \(1-a\) is not generally a unit.

Lemma (conditional defect transport). Let \(J\) be a degree-\(D\) pseudoideal over a field, let the five values have degree at most \(L\ge1\), let \(\deg P\le p_0\), and suppose \(Pa\in J\). If \(p_0+K+3L\le D\), the two maps on any subspace \(U\subseteq V_K\), \[ f\longmapsto([PR_1f],[PR_2f]),\qquad f\longmapsto([PR_1f],[PTf]), \] have identical kernels and hence equal ranks. No Booleanity is required for this algebraic statement. Semantic use requires the displayed interpretation and one coherent source choice.

Proof. If both original components vanish, then \(PTf=P(1-a)R_2f+PvR_1f\in J\) by bounded absorption. Conversely, \[ PR_2f=PTf-PvR_1f+PaR_2f. \] The first two terms vanish under the transformed kernel conditions, and the last belongs to \(J\) by \(Pa\in J\). Every absorption fits \(p_0+K+3L\le D\), since \(\deg R_i,\deg T\le2L\). The domain is the same finite-dimensional space in both directions, proving rank equality. \(\square\)

Without the antecedent condition the conclusion fails already for constants: take \(P=1,a=1,b=u=v=0,c=1,J=0\). Then \(R_1=0,R_2=1,T=0\). This is a control of the algebraic hypothesis, not a legal counterexample to an entire Frege proof. For ideal-image sums instead of stacked maps one also has \(P(R_1V_{K+L}+R_2V_K)=P(R_1V_{K+L}+TV_K)\) modulo \(J\), with the same ceiling and condition. That version pays an enlarged cofactor space; it is not the argument proving the joint-kernel result.

The correction matters: swapping the implication and conclusion produces a replay discrepancy rather than the semantic approximation defect. Replaying a proven antecedent can relate them, but cannot identify their error spaces for free. The constant control above also shows why a unit cancellation in an unrestricted polynomial module is not the same as conditional bounded absorption.

Code weights omit coefficient geometry

Proposition (weight profile escape gap). With the seven nonzero binary points labelled as in the preceding counterexample, two coordinate-permutation-equivalent three-dimensional codes have generic escape ranks two and three for multiplication by \(\alpha y_1+\beta y_2+\gamma y_3\). Thus all generalized Hamming weights, of the codes and their duals, fail to determine this escape rank.

Proof. Use \(U_0=\langle\delta_1+\delta_6+\delta_7,\delta_2+\delta_5+\delta_7,\delta_3+\delta_5+\delta_6\rangle\), whose escape matrix and rank two were proved in the preceding entry. Exchange evaluation coordinates 4 and 7, while retaining the fixed point labels of the multiplier. The new basis has supports \(\{1,4,6\},\{2,4,5\},\{3,5,6\}\). Modulo pivot coordinates \(1,2,3\), its nonzero escape matrix on columns \(4,5,6\) is \[ \begin{pmatrix} \alpha+\gamma&0&\alpha+\beta+\gamma\\ \beta+\gamma&\alpha+\beta+\gamma&0\\ 0&\beta+\gamma&\alpha+\gamma \end{pmatrix}. \] Its determinant is \((\alpha+\beta+\gamma)(\alpha+\beta)^2\ne0\), so the generic rank is three. Coordinate permutation gives a support-size-preserving bijection on every subcode and also permutes the dual code, proving the weight-profile assertion. For reference the common hierarchy is \((3,5,6)\): every nonzero word has weight three or four, every two-dimensional subcode has support at least five because each supported coordinate occurs in exactly two of its three nonzero words, and two basis words attain five; the total support is six. \(\square\)

This rejects determination by unlabelled code weights alone. It does not refute inequalities retaining the incidence of the evaluation labels, or the existing queued generalized-weight questions. The counterexample changes no coefficient field or legal choice set.

A scope check for quantum cleaning

Proposition (one-sided cleaning gap). Let \(G\) be a finite connected bridgeless graph with an edge, and let \(C=\operatorname{im}\partial\subseteq\mathbb F_3^E\) be its oriented cut space. On complex qutrits indexed by edges, consider the uncharged stabilizer group \(S=\{Z(c):c\in C\}\), where \(Z(c)|x\rangle=\zeta^{c\cdot x}|x\rangle\) and \(\zeta\) is a primitive complex cube root. This code has a nontrivial logical phase operator supported on each single edge, and therefore distance one.

Proof. All these diagonal operators commute, and the common eigenspace of eigenvalue one contains \(|0\rangle\), so it is nonempty. For an edge \(e\), the coordinate vector \(\mathbf1_e\) is not a cut: if \(\partial s=\mathbf1_e\), the potential \(s\) is constant along every edge of the connected graph \(G-e\), hence constant everywhere, a contradiction. Thus \(Z(\mathbf1_e)\) commutes with \(S\) but is not in it. It acts nontrivially on the code: a cycle through \(e\) gives an oriented vector \(x\in C^\perp\) with \(x_e\ne0\), and \(|x\rangle\) and \(|0\rangle\) are code states with different eigenvalues under that operator. The minimum nontrivial support is consequently one. \(\square\)

This is a test of the one-sided stabilizer translation, not of all quantum-code constructions. It uses an uncharged complex model solely to check the proposed dictionary. The inconsistent charged system has no global solution space, and is not being identified with this code. Additional check types or a purely linear partial-cleaning construction are different questions.
