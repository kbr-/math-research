<p><strong>General statement.</strong> <a href="#parameter-grid-dependence">cor:parameter-grid-dependence</a> applies the existing truncated-kernel calculation to the full constant-coefficient ensemble of two complete blocks. Their parameter sets and old variable supports are disjoint, yet their direct-sum weight kernels violate relative-dimension independence at every intermediate old-degree cutoff. A full degree-weighted tensor space restores factorization, with its full window still charged.</p>
<p><strong>New mathematics.</strong> An all-parameter ensemble version of the earlier cutoff obstruction, not another adverse single map. It clarifies the two different domains on which the proposed locality argument could operate. The full-degree repair is an application of the recorded filtered criterion.</p>
<p><strong>Goal progress.</strong> Unchanged. No useful source-specific conditional activity or simultaneous weight construction is supplied. The example is completely normalizable; it rejects automatic kernel independence, not the lower-bound route or ordinary probability independence.</p>
<h4>Two legitimate domains</h4>
<p>Fix a candidate weight \(W\). After degree-bounded coefficient classes and representatives are chosen, each source membership condition is an ordinary event on a finite parameter grid. Events depending on disjoint parameter sets are independent in its uniform product measure. This is valid even if their old polynomials mention the same old variables. What is missing is a quantitative bound for the event that all relevant weighted source equations fail, or a proof that an affordable local solution exists for this same \(W\). Pointwise approximation at one old assignment is not that event.</p>
<p>To search over weights as well, one can instead take a direct sum
\[
\mathcal V_K=\bigoplus_{\lambda\in\Lambda} H_K,
\]
where \(H_K\) is the surviving old degree-\(K\) weight space and each parameter \(\lambda\) selects a global map. Error operators act block-diagonally. A nonzero simultaneous kernel means that at least one parameter fiber has a nonzero successful weight. But the dimensions of these kernels include the shared old degree filtration, not only the product measure on \(\Lambda\). The following complete-source control tests exactly this second construction.</p>
<h4 id="parameter-grid-dependence">Parameter grid dependence</h4>
<p>Work over \(\mathbb F_2\) in the Boolean function algebra on \(n\) old variables. Take \(r,h\ge1\), \(n\ge2r\), and two disjoint sets \(S_1,S_2\) of \(r\) old variables. Block \(i\) is the complete accuracy-\(h\) ENS block on
\[
(1,(x_j)_{j\in S_i}).
\]
Its constant coefficient grid \(\Lambda_i\) contains all \(h\)-by-\((r+1)\) binary matrices. Thus no coefficient assignment within the constant-map class is discarded. Fresh field images vanish at every grid point. Write \(P_i(\lambda_i)\) for its product. The companion tuple has the same kernel as multiplication by \(P_i\), since it contains the companion for input one; conversely a function killed by \(P_i\) is killed by every input times \(P_i\).</p>
<p>Let \(V_K\) be the old degree-at-most-\(K\) function space, \(N_m(K)=\sum_{j=0}^{\min(m,K)}\binom mj\), \(\Lambda=\Lambda_1\times\Lambda_2\), and \(\mathcal V_K=\bigoplus_{\lambda\in\Lambda}V_K\). Let \(\mathcal X_i\) be the kernel of block \(i\)'s complete companion map on this direct sum. All function calculations can be interpreted in the degree-truncated Boolean pseudoideal with \(D\ge K+2h+1\), which pays the original product/companion costs \(2h,2h+1\). This is a satisfiable control, not the charged hard base.</p>
<p><strong>Corollary (parameter grid dependence).</strong> For every \(1\le K<n\),
\[
R(\mathcal X_1\cap\mathcal X_2)
<R(\mathcal X_1)R(\mathcal X_2).
\tag{1}
\]
Writing \(a=1-R(\mathcal X_i)\), the conditional error fraction satisfies
\[
1-R(\mathcal X_2\mid\mathcal X_1)>a.
\tag{2}
\]
Thus neither the exact relative-dimension local lemma nor the one-sided Shearer condition accepts a nonedge at the natural initial rank fractions solely from this coefficient and input disjointness. At \(K\ge n\), equality returns.</p>
<p><strong>Proof by averaging the existing flat calculation.</strong> For a chosen matrix, the product \(P_i\) is the indicator of the affine system given by its \(h\) row equations. It is zero if the system is inconsistent. Otherwise it is the indicator of a nonempty affine flat of codimension \(j\), \(0\le j\le\min(h,r)\), within its variable block. Let \(\mu_j\) be the probability of this latter case. The missing probability is the inconsistent case. In particular \(\mu_1>0\): choose one nonzero coordinate row and all remaining rows zero.</p>
<p>A binary invertible affine change within each disjoint block puts its flat in coordinate form, preserving the Boolean degree filtration in both directions. The <a href="#entry-2026-10-07-relative-dimension-polymer">cover-basis calculation</a> then gives single multiplication rank \(N_{n-j}(K)\). If both flats are nonempty with codimensions \(j,k\), the two-kernel dimension is
\[
N_n(K)-N_{n-j}(K)-N_{n-k}(K)+N_{n-j-k}(K).
\]
The formula includes zero codimension. If one product is zero, its kernel is the whole domain. Averaging over the independent complete grids therefore gives
\[
a=\sum_j\mu_j\frac{N_{n-j}(K)}{N_n(K)},\qquad
b=\sum_{j,k}\mu_j\mu_k\frac{N_{n-j-k}(K)}{N_n(K)},
\]
and
\[
R(\mathcal X_i)=1-a,\qquad
R(\mathcal X_1\cap\mathcal X_2)=1-2a+b.
\tag{3}
\]</p>
<p>The earlier strict log-concavity calculation for \(N_m(K)\) gives, for \(j,k>0\),
\[
N_{n-j-k}(K)N_n(K)
<N_{n-j}(K)N_{n-k}(K).
\tag{4}
\]
For clarity, its consecutive ratios \(N_{m+1}(K)/N_m(K)\) are nonincreasing in \(m\), and strictly drop once the cutoff is active. Compare the \(k\) ratios ending at \(n-j\) with those ending at \(n\). The final comparison is strict because \(K<n\); this proves (4) also for unequal \(j,k\). If either is zero there is equality. Since \(\mu_1>0\), summing gives \(b<a^2\), proving (1).</p>
<p>There is positive probability of the zero product, for example a constant-one row, so \(a<1\); there is also positive probability of the product one, so \(a>0\). From (3) the conditional error fraction is \((a-b)/(1-a)>a\), proving (2). If \(K\ge n\), every \(N_m(K)=2^m\), and all the comparisons become equalities. \(\square\)</p>
<h4>A paid graded repair</h4>
<p>On the full old space \(V_n\), keep its entire degree filtration and use the positive Hilbert weight \(z^{\deg}\), \(0<z\le1\). For a nonempty flat of codimension \(j\), its restriction image has Hilbert polynomial \((1+z)^{n-j}\), by the same degree-preserving affine change. For the independent two-block ensemble, put
\[
a(z)=\sum_j\mu_j(1+z)^{-j}.
\]
The exact filtered dimensions are
\[
H_\varnothing(z)=|\Lambda|(1+z)^n,\quad
H_{\{i\}}(z)=H_\varnothing(z)(1-a(z)),\quad
H_{\{1,2\}}(z)=H_\varnothing(z)(1-a(z))^2.
\tag{5}
\]
Thus coefficient independence and disjoint old supports do factor on this full positively weighted tensor space. This is a positive repair of the cutoff shortcut, not a declaration that dependency methods are unusable.</p>
<p>To return a degree-\(K\) weight, the <a href="#entry-2026-10-07-filtered-shearer-tail">filtered Shearer theorem</a> must still beat the tail
\[
|\Lambda|\sum_{j>K}\binom njz^j.
\]
Moreover every error map used on \(V_n\) needs its full old window, not merely the returned \(K\). In a degree-\(D\) pseudoideal that means paying the old degree \(n\) plus the error degree. The hard family currently supplies only a proper window \(D=\gamma n<n\). The full-function factorization in (5) therefore cannot be transplanted into that charged quotient for free. A smaller, source-compatible filtered domain or genuinely bounded conditional ranks remains missing.</p>
<h4>Why this does not reject the source or fixed-weight approach</h4>
<p>These blocks are deliberately easy: select the input one in the first row of each block. Both products become zero, all companions and fresh fields vanish, and the weight one survives. The entire source has a simultaneous constant map. This positive control is part of the test. Neither (1) nor a failed particular Shearer parameter choice proves a lower bound on optimized errors.</p>
<p>Ordinary events on the coefficient grid with weight one are still independent. The failure concerns relative dimensions after the old weight space has been included and truncated. At one source level with earlier values fixed, independent coefficient choices can be made block by block if each block already has a suitable map for one common weight. The general source problem lacks precisely that common-weight feasibility and its degree bound; across levels, shared earlier products also couple the events. No new nonemptiness theorem follows from the grid description.</p>
