## Proof scope

This analytic cycle extends the existing sharp mixed-mode Booleanity argument
to the new goal-normalized source family. Retained ENS products, literal zero
and one, projections/products of actual earlier values, field selectors, and
sharp old-base-zero products have NS Booleanity through twice their current
degree without discarded goal assumptions. The current degree is used when
rebuilding certificates; blindly specializing an older bound is insufficient.

The proof also localizes to the current polynomial's ENS level support within
this portfolio. It uses ordinary polynomial support before Boolean or field
reduction. Generic earlier-zero witnesses or arbitrary new Boolean generators
do not inherit this support property without their own verified hypotheses.

After the protected-clause PHP endpoint, process levels from bottom to top.
Remove a block when its literal input span contains one, or pack a degree-ordered
basis of actual inputs when rank is at most accuracy. At each level/accuracy,
use the existing affine quotient to share equal surviving input spans. Later
levels cannot change earlier input spaces, so one ordered pass suffices.
The actual PC refutation degree is unchanged. No PC-to-NS conversion is asserted.

The remaining tuples are independent Boolean bases, have rank greater than
their accuracy, contain no nonzero constant in their spans, and define distinct
spaces within each level/accuracy. This is a normal form, not a proof that the
remaining blocks are essential or that no smaller ideal cover exists. No rank
calculation for an unspecified Frege proof was performed.
