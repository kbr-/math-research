Coefficient orientation for the next test

The existing binary-flat coefficient lemma gives a direct oracle, not a new coding theorem. For constant binary row matrices and a formal feature vector \(Z\), write the union product as the zero indicator of \(AZ=b(x)\), and the two separate products together as the zero indicator of \(BZ=c(x)\), with \(B\) the stack of their actual row systems. Here the old-affine parts remain in \(b(x),c(x)\). For every feature subset \(S\), at each fixed old Boolean \(x\), the coefficient of their difference as a function of formal \(Z\) is \[\mathbf1[\operatorname{rank}A_S=|S|,\ b(x)\in\operatorname{im}A_S] +\mathbf1[\operatorname{rank}B_S=|S|,\ c(x)\in\operatorname{im}B_S]\quad\text{in }\mathbb F_2.\] This follows by applying lem:binary-flat-coefficients-matroid twice, with the actual affine constants retained. Overlapping input groups use the common registry once, as in lem:overlap-row-defect; naive symmetric difference would be wrong. If raw old-affine variables are expanded as extra formal features, this oracle can lose the useful affine-flat factorization, so the next estimate must keep that part factored. The oracle and a cancelled coefficient do not bound a quotient image by themselves.
