Question and stopping point. For general-step, extend the rank-free pure-reader construction to old-affine higher references. Do not clamp the terminal blocks: leave their coefficients as variables and invoke the full old-target theorem. The stopping point is an exact weighted certificate transfer and the count range that theorem actually supports. This gives a broader grammar, but not an unrestricted source theorem.
1. Adaptive internal decisions and a terminal reference system
Fix \(p\) and the full old functional system \(\mathcal F=\mathcal F^{\mathrm{fun}}_{N+1,N}\). Take a finite acyclic complete ENS source with private coefficient blocks, positive accuracies, and inputs \(g_{b,i}=H_{b,i}(X,(P_c)_{c<b})\). Earlier coefficients occur in these inputs only through genuine whole products; proofs may use arbitrary original cofactors. Remove identically zero tuples by their exact product value one before defining formal weights. Keep every remaining original degree \(d_{b,i}\), \(\delta_b=\max_i d_{b,i}\), \(w_b=h_b(\delta_b+1)\), and \(e_{b,i}=w_b+d_{b,i}\).
Call a block internal if a later input reads its product, and terminal otherwise. Process internal blocks in a topological order, assigning \(\epsilon_b\in\{0,1\}\). At each block, including terminals at the end, form
\[ L_{b,i}(X)=H_{b,i}(X,(\epsilon_c)_{c<b}). \tag{GT-reference} \]
Require these visited reference inputs to be affine. A sufficient syntactic condition is that every \(H_{b,i}\) has degree at most one in the old variables, with arbitrary polynomial coefficients in the formal earlier products. The more general visited-reference condition suffices; no claim is made that arbitrary compiled sources meet it.
Maintain an old polynomial \(f\), a charge \(t\), and a memoized decision for each distinct proper nonzero internal reference span \(V_b=\operatorname{span}_{\mathbb F_p}\{L_{b,i}\}\). Initially \(f=1,t=0\). Write \(I_j=\mathcal I_j(\mathcal F)\). For a new proper span, choose an affine basis \(F_1,\ldots,F_r\) and test \(fF_j^{p-1}\) in \(I_{t+p-1}\). If one is outside, replace \(f\) by that product, increase \(t\) by \(p-1\), record that probe, and set \(\epsilon_b=0\). Otherwise set \(\epsilon_b=1\) and retain the certificates for all probes. Zero spans receive value one; spans containing one receive value zero. Repeated spans use their earlier decision and probe/certificates by constant linear pullback. Terminal spans receive no decision.
This is the earlier greedy selection with adaptively generated affine spans. Every actual update explicitly preserves \(f\notin I_t\); later updates multiply all earlier certificates by the selected event and increase their cutoff by the same charge. Thus, if \(a\) is the number of distinct proper internal reference spans encountered and \(b\le a\) the number of successful nonzero-event selections,
\[ \deg f\le t=(p-1)b\le(p-1)a,\qquad f\notin I_t. \tag{GT-nonzero} \]
All tests are in the old system. Reference selection does not presuppose stability of an augmented source or feasibility of a family that depends on future decisions. This is an existence construction, not an efficient membership algorithm.
For every terminal block retain its own original coefficients and accuracy, but replace its inputs by \(L_{b,i}\). Let \(\Gamma_{\mathrm{term}}\) be the old functional system plus this complete one-level affine family, including all its coefficient field equations. Set \(T=1\) if every proper internal reference block has \(h_b\ge p-1\); otherwise set \(T=\max(1,p-2)\). A repeated proper type with a smaller accuracy uses the latter formula when needed.
Working transfer theorem. There is a substitution \(\Phi\) fixing old and terminal coefficient variables and replacing every internal coefficient by an old polynomial of degree at most \(T\), such that every source axiom \(A\) has
\[ f\Phi(A)\in\mathcal I_{t+T\deg A}(\Gamma_{\mathrm{term}}). \tag{GT-axioms} \]
Consequently a degree-\(D\) source NS or PC refutation, for \(D\ge\max(p,3)\), gives a degree-\(E\) PC proof of the old target \(f\) from \(\Gamma_{\mathrm{term}}\), where
\[ E=TD+t. \tag{GT-ceiling} \]
It is therefore impossible whenever \(\mathcal C_E(\Gamma_{\mathrm{term}})\cap\mathcal P^{\mathrm{old}}_{\le t}=I_t\). This is a sufficient old-target equality, not an assertion of augmented PC=NS. The same source lower bound holds over the weak base by functional strengthening.
2. Proof with original companion degrees
Internal reference maps. For a selected-zero proper span, write its recorded probe as \(F=\sum_i c_iL_{b,i}\). If \(h_b\ge p-1\), use the constant rows \((\alpha c_i)_i\) for \(\alpha\in\mathbb F_p^*\), and zero extra rows. Otherwise use first row \((c_iF^{p-2})_i\) and zero remaining rows. When applied to the reference tuple, either choice gives \(P_b^{\mathrm{ref}}=1-F^{p-1}\). The final weight contains the selected event, so \(fP_b^{\mathrm{ref}}\) is Boolean-zero with a certificate through \(t+p-1\).
For a forced-one span set all coefficients to zero, giving \(P_b^{\mathrm{ref}}=1\). Its stored certificates give \(fF_j^{p-1}\in I_{t+p-1}\). Multiplying by \(F_j\) and subtracting the old Boolean consequence \(f(F_j^p-F_j)\) yields \(fF_j\in I_{t+p}\), and hence \(fL_{b,i}\in I_{t+p}\). For a unit span use one constant row realizing \(\sum_i c_iL_{b,i}=1\), giving reference product zero; for the zero span use zero coefficients and reference product one. All chosen coefficient images have degree at most \(T\).
Transporting earlier errors. Inductively maintain, for each processed internal block,
\[ f(\Phi(P_c)-\epsilon_c)\in I_{t+Tw_c}. \tag{GT-values} \]
The final common \(f,t\) may be used throughout this proof, because every earlier greedy certificate has already been multiplied by all later events. The genuine-selector degree reflection gives weighted degree exactly \(d_{b,i}\) to the original formal input. Expand it into monomials and telescope one earlier product at a time, retaining any old-variable factors. Since old variables have weight one and are fixed, this proves
\[ f(\Phi(g_{b,i})-L_{b,i})\in I_{t+Td_{b,i}}. \tag{GT-inputs} \]
In particular \(\deg L_{b,i}\le d_{b,i}\). This inference uses the original formal degree, not the degree after the chosen values collapse the input.
Let \(\beta_{b,u,i}\) denote the coefficient image (the original coefficient variable for terminals). Compare each row factor using actual inputs with the same row factor using reference inputs. Its weighted difference is a sum of \(\beta_{b,u,i}f(\Phi(g_{b,i})-L_{b,i})\), with certificate ceiling at most \(t+T(\delta_b+1)\). Both row factors have ordinary degree at most \(T(\delta_b+1)\). Telescoping the \(h_b\) factors, then the outer input of each companion, gives
\[ \begin{aligned} f(\Phi(P_b)-P_b^{\mathrm{ref}})&\in I_{t+Tw_b},\\ f\bigl(\Phi(g_{b,i}P_b)-L_{b,i}P_b^{\mathrm{ref}}\bigr) &\in I_{t+Te_{b,i}}. \end{aligned} \tag{GT-products} \]
For terminals, these old-generator certificates are interpreted in the ring with retained terminal coefficients; their multipliers obey the same displayed bound. They need no property of the terminal source beyond containing the old generators.
For a proper internal reference, \(\delta_b\ge1\), hence \(Tw_b\ge p-1\). Whenever \(L_{b,i}\ne0\), its proper span contains no nonzero constant, so \(d_{b,i}\ge1\) and \(Te_{b,i}\ge p\). The selected-zero reference product and companion certificates therefore fit (GT-values) and (GT-axioms); the forced-one companion certificates also fit. A zero reference input contributes no residual companion. Unit and zero spans have exact reference identities. This closes the internal induction.
For a terminal block, \(L_{b,i}P_b^{\mathrm{ref}}\) is an actual generator of \(\Gamma_{\mathrm{term}}\). Its degree is at most the original \(e_{b,i}\), so multiplying it by \(f\) fits the ceiling in (GT-products). This proves every terminal companion case without choosing terminal product values. Internal coefficient fields map to old polynomials vanishing on the Boolean cube, certified through \(pT\); terminal fields remain generators. Weighting adds \(t\). Old generators are fixed. Thus all actual source axioms satisfy (GT-axioms).
For NS replay, each original cofactor has degree at most \(D-\deg A\), so its image times the weighted axiom certificate stays within \(TD+t\). For PC replay, maintain the line \(f\Phi(q)\). Addition is immediate. A legal variable multiplication has predecessor degree at most \(D-1\), unless it is zero; multiply by the polynomial image of that variable monomial by monomial. Intermediate target degrees are at most \(T(D-1)+t+T\), and the earlier derivation is reused at ceiling \(E\). The final source line one therefore yields \(f\in\mathcal C_E(\Gamma_{\mathrm{term}})\), contradicting (GT-nonzero) under the stated old-target equality. \(\square\)
3. What the existing full-board window actually buys
Assume polynomial original source inventory and fixed exponents \(\alpha,\eta\ge0\), with \(D\le N^\alpha\operatorname{polylog}N\) and \(a\le N^\eta\operatorname{polylog}N\). Since \(T\) is constant for fixed \(p\), put \(\zeta=\max(\alpha,\eta)\). The existing full old-target theorem applies at target cutoff \(t\le(p-1)a\) and proof ceiling \(E=TD+t\) whenever
\[ 2\max(\alpha,\eta)+\eta<1. \tag{GT-power} \]
Working corollary. Under these hypotheses and the affine-reference condition, sufficiently large instances have no degree-\(D\) source PC or NS refutation. Arbitrarily many polynomially indexed terminal blocks remain uncharged in \(a\); arbitrary internal dependency depth introduces no extra multiplier beyond original degrees. If an independent bound on the actual successful-event count \(b\) is available, it may replace \(a\) in this power test. The proof supplies no general such saving.
At polylogarithmic \(D\), this gives every fixed \(\eta<1/3\), not the pure-reader range \(a=o(N)\). The loss is real in this sufficient ledger: for \(a=\Theta(N/\log N)\), the available old-target window would need to preserve an almost-linear-degree \(f\), far outside its established range. We do not claim that the source is easy or that the equality is false there. If no internal type needs a successful event, \(t=0\), and the same ledger recovers the affine endpoint's \(D=N^{\alpha}\operatorname{polylog}N\), \(\alpha<1/2\), range.
Scope controls. This does not contradict the local-density obstruction: one global old weight and one complete terminal affine family are used, not separately feasible marginals. The mixed-target counterexample is not an old target over one affine layer. The earlier graph reference criterion obtains its internal zero clamps from high rank; this one allows arbitrary internal ranks but pays the greedy charge and invokes a different full-board preservation theorem. Neither criterion automatically implies the other's hypotheses. The pure-reader theorem retains its stronger count range by eliminating all coefficients and using the old linear barrier directly.
Route outcome and next task. A substantive weighted transfer now admits old-affine parts at every internal stage, so the earlier purity requirement is not absolute. The general-step obligation is still open: affine references after internal decisions and an affordable global internal charge are sufficient hypotheses, not facts about every compiled source. Next audit these hypotheses against the actual source compiler, including equivalent representations and naming costs, before refining more special families. Stop at a proved coverage range or a precise compiled-source obstruction; do not infer a small charge merely from fixed depth.
