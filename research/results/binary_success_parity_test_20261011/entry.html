Row success parity

Lemma. Let \(\Omega\) be finite and \(\mathcal B\) the set of Boolean functions on \(\Omega\), with pointwise multiplication. Let a finite row-parameter set \(A\) give functions \(q_a\in\mathcal B\); distinct parameters may give identical functions. Let \(\sigma:\mathcal B\to\mathbb F_2\) be any predicate. For every integer \(h\ge1\), \[\sum_{(a_1,\ldots,a_h)\in A^h}\sigma(q_{a_1}\cdots q_{a_h}) =\sum_{a\in A}\sigma(q_a)\quad\text{in }\mathbb F_2.\] The analogous identity holds for any finite number of blocks, with independent identical row domains within each block and an arbitrary joint predicate of their product functions: replace each positive number of rows by one row in the parity count.

Proof. Use the formal monoid algebra \(\mathbb F_2[\mathcal B]\), whose basis symbol \([f]\) is distinct for every Boolean function and whose multiplication is \([f][g]=[fg]\). This is not the old charged quotient. Put \(Q=\sum_{a\in A}[q_a]\). Commutativity, characteristic two and pointwise idempotence give \(Q^2=\sum_a[q_a^2]=Q\), so \(Q^h=Q\). Extend \(\sigma\) linearly from basis symbols to this formal algebra; applying it gives the identity. Repeated parameters are counted with their multiplicities before reduction. For several blocks use \(\mathcal B^M\) with componentwise multiplication, and a separate idempotent \(Q_b\) changing just component \(b\). Then \(\prod_b Q_b^{h_b}=\prod_bQ_b\). No enumeration of the very large function set is proposed. \(\square\)

If \(A=\mathbb F_2^s\), the full coefficient in all \(hs\) row bits of the Boolean indicator of success is consequently the parity of the one-row successes. More generally this equality holds pointwise in any other fixed parameters, such as a weight chart; further coefficient extraction in those parameters preserves it. The lemma requires a predicate of the product functions. A condition reading raw row parameters individually need not satisfy it.

The paid fresh-source interpretation

Fix a binary degree-\(D\) pseudoideal \(J_D\) containing Booleanity, a weight \(w\) of degree at most \(b\), and fixed old input tuples \(g_{a,i}\) of degree at most \(\delta_a\). In block \(a\), every row uses the same finite parameterization of binary polynomial coefficients \(\beta_{a,i}(y;u)\), of degree at most \(T\ge1\) in the old variables. Its row function is \[q_{a,u}(y)=1+\sum_i\beta_{a,i}(y;u)g_{a,i}(y).\] Assume \(h_a\ge1\) and \[b+\max_a\{h_a(T+\delta_a)+\delta_a,\ 2T\}\le D.\] Define success to mean \(w\notin J_D\) and \(wg_{a,i}P_a\in J_D\) for every actual companion, \(P_a=\prod_{v=1}^{h_a}q_{a,u_v}\). All coefficient-field images vanish at the displayed bound: binary polynomials obey \(\beta^2+\beta=0\) modulo the old Boolean ideal through degree \(2T\).

This success condition depends only on the functions \(P_a\) on the unconstrained old Boolean cube. If two such products are the same function, their difference is a Boolean-ideal element. After multiplication by \(wg_{a,i}\), monic Boolean reduction certifies it through degree \(b+h_a(T+\delta_a)+\delta_a\le D\), so it lies in \(J_D\). This does not interpret the proper charged pseudoideal as a function algebra of satisfying assignments. Extend the predicate arbitrarily to Boolean functions not realized in the permitted degree window; the lemma only uses its values on realized products.

Thus the full-row parity equals the count obtained by keeping one active row in each original block and setting its other rows to zero. The success predicate is evaluated at the same \(D\), same weight and same original source accuracy; no original cost is reduced by that zero padding. An original degree-\(B\) proof replay additionally pays \(b+TB\le D\), with \(B\) covering all original companions, fields and earlier interpreted generators. Different dictionaries between blocks are allowed, but rows within a block must share one dictionary. Earlier choices are fixed. Later inputs reading raw coefficient variables are not covered by the product-only success predicate. A one-batch count is not a complete all-level simulation theorem.

The earlier integer coefficient-kernel counts retain more information than this parity. Reducing their fixed-space unrestricted binary formula modulo two also loses dependence on the positive row count, but their intersection criterion and its word space are not the actual product-success predicate above. The present proof deals with the actual prefix functions and does not assume equality with that relaxation.

A chart that passes where full parity fails

Corollary. For every \(h\ge2\), \(T\ge1\), put \(r=h(T+1)\). Use independent Boolean inputs \(x_1,\ldots,x_r\), one complete accuracy-\(h\) block, coefficient maps of degree at most \(T\) in these variables, weight one, and a Boolean-only base through any \(D\ge T(2h+1)\). Parameterize each row by all coefficients of monomials of degree at most \(T\), identically and independently in every row. The full coefficient of the success indicator is zero, although successful choices exist. There is an explicit asymmetric affine parameter chart in \(h\) bits \(\tau_1,\ldots,\tau_h\) on which that indicator is \(\prod_u\tau_u\), with full coefficient one.

Proof. A one-active-row product has degree at most \(T+1<r\) and value one at the all-zero input. If all companions vanish as Boolean functions, the product must vanish at every other input. Its unique multilinear representative would then be \(\prod_{j=1}^r(1+x_j)\), of degree \(r\), a contradiction. The Boolean-only base introduces no extra identifications of functions. This is the historical pointwise degree barrier, applied to one active row. The parity lemma therefore makes the full-grid coefficient zero.

Partition the inputs into ordered groups \(G_u\) of size \(T+1\). In row \(u\), give the \(j\)-th input of its group coefficient \(\prod_{v<j}(1+x_v)\), with the order within that group; multiply the coefficient of the last input by \(\tau_u\). All coefficients outside the group are zero. These are degree-at-most-\(T\) maps, and their monomial coefficients are affine functions of \(\tau\). When every \(\tau_u=1\), telescoping gives \(q_u=\prod_{x\in G_u}(1+x)\), hence \(P=\prod_{j=1}^r(1+x_j)\) and all companions vanish. If some \(\tau_u=0\), assign only the last input of that group the value one and every other input zero. Every row function is then one, so that input's companion is one. Hence exactly the all-one chart point succeeds, giving the displayed indicator.

This is an explicitly parameterized instance of historical factor packing, not a new construction of a successful source. The companion certificates have degree at most \(r+1\), and field certificates degree at most \(2T\). Both fit \(T(2h+1)\), since \(r+1=h(T+1)+1\le T(2h+1)\). The original companion cost is still \(2h+1\) and map degree \(T\), exactly the stated replay ceiling. The base is a consistent Boolean cube, not a claimed hard family. \(\square\)
