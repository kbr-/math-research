Nested cores allow incomparable full input spaces

The historical core–residual theorem is more flexible than requiring the full input spaces to form a chain. For same-level fresh blocks over a retained field/Boolean base, choose nested cores \(U_1\subseteq\cdots\subseteq U_s\), \(U_a\subseteq V_a\), generated through degree \(\gamma\). Let \(r_a=\dim(V_a/U_a)\), with actual residual representatives of degree at most \(\eta_a\). In the binary case it transforms an incoming PC ceiling \(D\) to \[ TD+\gamma,\qquad T=\max_a\max\{1,\eta_a(\lceil r_a/h_a\rceil-1)_+\}. \] For zero residual rank use \(\eta_a=0\). The full spans may be incomparable. In particular \(r_a\le h_a\) gives \(T=1\) even for nonlinear residuals; affine residuals permit \(r_a\le2h_a\).

The source proof was read in full, including its packed coefficient construction. It repeatedly reuses the same original proof to learn the nested core inputs, then absorbs each residual with an explicit packed zero test. The degree transformation is the key deliverable: at several batches, maps \(d\mapsto T_{\mathcal B}d+\gamma_{\mathcal B}\) compose as affine functions, so multiplicative factors cannot be hidden by counting only levels. Quotient versions require supplied, degree-bounded base derivations; membership in the unrestricted ideal of an inconsistent base is not a certificate.

The maximal cores for a fixed order are suffix intersections. The exact residual-radius theorem shows that nondecreasing dimension order minimizes \[ R_*=\max_{\varnothing\ne S} \left(\min_{a\in S}\dim V_a-\dim\bigcap_{a\in S}V_a\right). \] Thus arbitrary ordering search is unnecessary for this unweighted residual-radius objective; it does not by itself optimize unequal degree or accuracy costs. An invertible common change of coordinates preserves these dimensions and intersections; any improvement in the next matrix test must come from the subsequent restriction or a paid change of representatives, not the basis change alone.

Its extra cost is \((p-1)\sum_\nu\deg f_\nu\), and the historical conclusion is an ordinary augmented design. The nonzero cell is found greedily, not by enumerating every feature assignment. This is a structural hypothesis, not a consequence of polynomial proof size.

The whole-column variant charges only one degree per shared PHP column: the empty state and each occupied state have affine indicators in the Boolean column-exclusive ring.
