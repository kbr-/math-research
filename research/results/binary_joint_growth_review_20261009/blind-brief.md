Goal and bounded available results — blind architecture stage

Goal: for each fixed depth d, exhibit a family of tautologies/unsatisfiable
formulas of encoding length L growing to infinity requiring superpolynomial
symbol size in depth-d AC0[2]-Frege. Family may depend on d, not on the
polynomial exponent to be excluded. Any family is acceptable. The all-prime
goal is separate; binary success is useful. No claim of a proved goal.

Available results (statements only for architectural comparison):
1. Complete binary CNF-to-PC compiler. For the audited finite Boolean/MOD2/MP
presentation and coherent flat clause profiles, a hypothetical bounded-depth
Frege proof yields a PC refutation of old CNF axioms plus complete acyclic
ENS blocks through c L0, c=max(Mfr,10), L0<=(d+1)h^d. No proof-height factor.
Literal clauses of width w require h>=max(1,w). O(S) blocks and safe O(S^2)
input slots for symbol size S. Every ENS block retains companions
g_i product_u(1-sum_j r_uj g_j), and fresh binary fields r_uj^2-r_uj.
The upper source grammar includes affine mixtures of earlier chosen products;
no forest, disjoint support or bounded reader-rank assumption is established.

2. Hard binary base. Charged mod-three Tseitin on bounded-degree expanding
graphs has a proper binary Boolean polynomial-calculus pseudoideal through
D=gamma n for fixed positive gamma in the recorded window. Its Fourier
quotient has cut-code coset basis and exact filtered multiplication; no global
solution model for the inconsistent system is assumed. Encoding length O(n).

3. Weighted replay. One coherent degree-T polynomial coefficient interpretation
and a binary old weight W of degree b with W outside J_D yield a contradiction
if all weighted original source generators vanish in the same J_D and
b+TB<=D, B the original source-refutation degree. Original generator products
and coefficient fields must all be paid. Complete source elimination is only
sufficient; other routes to the Frege bound are allowed.

4. Source tools. Complete old-affine blocks admit polynomial coefficient
packing from actual input rank r at degree max(1,delta(ceil(r/h)-1)).
Nested affine-core/residual packing uses residual ranks instead, with supplied
relations paid; arbitrary nonlinear shared inputs are not covered.
There is also exact one-block PC elimination at additive input-degree cost
for retained inputs, with the recorded hypotheses, so sequential elimination
pays an inventory-dependent sum.

5. A proper Boolean degree-D kernel containing an unsatisfiable input must
have a free coordinate algebra on D-1 selected old variables (linear
independence of all its monomials). Weighted version uses D-deg W-1.
All pins on selected free coordinates survive but pay their count in ordinary
restriction replay. This is not an uncharged full Boolean module with
commuting outside operators.

6. A parallel notebook searches for near-half PC degree families. It has
screening/upper bounds and the preceding kernel-dimension theorem, but no
qualifying family. It should not be treated as an available lower-bound
theorem. The original bit-PHP Res(parity) lower bound is proved separately.
