unit/annihilator witnesses to lie in Gamma through level s. Original Boolean
variables have level zero. Keep structural levels before polynomial cancellation
and the source's flattened OR convention.

gives an input refutation in the positive case, or a proof of each input in the
negative case, using only Gamma below d. The bound is
max(A*,U*+2L,max(M,10,p-1)L), with M the fixed Boolean frame leaf-count bound.

## Applications and counterexample

For A or not A or C, with A beginning in OR and C a pure wide disjunct, the
root inputs include A's flattened tuple and its value a. An earlier conditional
unit proof yields 1-a, so adding the a input refutes the tuple. Copy agreement
aligns independent occurrences. The C root can be ignored even when it is a
proper block at the same level as the outer boundary.

Fresh-root zero specialization alone leaves other blocks at that level. The
existing assignment-tree construction gives the exact PHP inputs a PC-five
refutation at accuracy one using exponentially many level-one peers. A separate
fresh ENS root on the degree-two PHP tuple has product degree three; weighting
that refutation by its product gives a PC-eight value proof. Removing every
level-one peer would give a base PHP refutation through eight, contradicting
the recorded n/2+1 lower bound when n>=16. This is a reuse of the generic
exponential-family obstruction, not a polynomial-family source lower bound.
