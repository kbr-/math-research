# Owned scratch source retrieval

The existing arXiv downloader now admits the active Codex actor's managed scratch subtree when Git
ignores it and tracks no files in the destination. External scratch remains supported. It rejects
foreign managed trees, missing ownership, invalid inherited owner paths, parent traversal, symlink
ancestors and contents, hard-linked files, existing nested repositories and Git metadata ancestors.
Tar members that would introduce Git metadata are skipped alongside escaping members and links.

Protected jobs receive the managed path from the launcher in MATH_CODEX_SCRATCH; the raw session
identity is not forwarded. Native identity takes precedence in direct calls. The launcher leaves
Claude's environment selection unchanged.

## Verification

- The final full framework run passed 1,041 tests in 9.1 seconds. The complete output is in
  framework-output.txt. Earlier runs and the initial test-fixture failure remain in this timing
  session's archive. That fixture cleared the systemd environment while testing argument

- The mutmut 3.8.0 sweep before the final Git-metadata-ancestor correction selected the
  destination-validation function: 128 mutants, 114 killed, 14 survived, none uncovered in that
  selected scope. The metadata and output are mutation-results.json and mutation-output.txt. Two

  fourteen diffs were inspected by the agent and reviewer. Other functions generated by mutmut were
  outside this selected sweep. survivor-diffs.txt preserves the earlier 22-survivor output; final
  survivors are IDs 4, 5, 24, 26, 49, 58, 66, 68, 81, 85, 106, 107, 112 and 113, whose diff contents
  are unchanged. The other eight were subsequently killed.
- Seven generated mutants were replayed individually after a four-test clean control. Each run
  completed four tests and failed a named relevant test; one replay was diagnostic-only. Separate
  targeted checks removed the ancestor-link guard, the CLI's pre-fetch validation, and the runner's
  scratch propagation. Each failed its corresponding test after a clean control. All mutation copies
  were isolated from production files and restored after use.
- Regression tests first failed for a nested repository in the output and Git metadata in a tar
  payload. Review then found that Git discovery fails inside a checkout's metadata directory; the
  new metadata-destination regression failed on the original implementation, including reaching the
  mocked network. An explicit ancestor guard now rejects this case before fetching. The final full
  suite passed all these tests, along with the original external-scratch, extraction and
  title-identification tests. This correction was checked by the same reviewer.

Mutation reproduction used an owned scratch project with src/arxiv_source.py, src/codex_state.py and
tests/test_arxiv_source.py copied from this checkout. Its mutmut configuration selected
source_paths=["src"], only_mutate=["src/arxiv_source.py"] and the ManagedDestinationTest class;
pytest used pythonpath=["src"]. The protected run invoked mutmut with eight children and the
arxiv_source.x_validate_destination__mutmut_* selection. Targeted replays shared one isolated source
copy, so application, test and restoration were sequential. No dependencies were installed.

## Real retrieval

The downloader fetched arXiv:1210.0819v3 through the protected launcher into the assigned owned
scratch on this repository, before the final metadata-ancestor guard. The existing destination held
one source file. It downloaded 7,574 bytes and unpacked one 23,240-byte TeX file. Its title and
author were identified as William Crawley-Boevey, *Decomposition of pointwise finite-dimensional
persistence modules*. The TeX was opened and read; the retrieval has SHA-256:

a4eeb1477424ce9780e8d07c8d2bab7557f575a43c1926435712305ba69a19f5

The complete retrieval output is retrieval-output.txt. The paper's text remains private and is not
committed. This verifies source access, not a new mathematical result or an independent
certification of the paper's proofs. No retrieval speedup is claimed.
